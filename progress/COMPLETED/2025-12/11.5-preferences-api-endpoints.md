# Task: Preferences API Endpoints

**Phase**: Phase 11 - Backend Connectivity & System Settings **Task ID**: 11.5
**Status**: TODO **Started**: Not started **Completed**: Not completed

## Description

Create API endpoints for reading and updating user preferences. Endpoints:

- GET `/api/preferences` - get all preferences
- GET `/api/preferences/{key}` - get single preference
- PUT `/api/preferences/{key}` - update preference
- POST `/api/preferences/reset` - reset to defaults

Integrate with Data Logger service (owns database) or Core Daemon.
