# 12.6 Notes App

## Status: COMPLETED
**Started**: 2025-12-25
**Completed**: 2025-12-25

## Description
Implement a Notes app similar to iOS Notes. Users can create, edit, and delete notes with basic rich text formatting (headers, bullet points).

## Acceptance Criteria
- [x] Notes list view showing all notes with preview
- [x] Create new note functionality
- [x] Edit existing note
- [x] Delete note with confirmation
- [x] Rich text support: headers (H1, H2)
- [x] Rich text support: bullet points
- [x] Rich text support: bold/italic (optional)
- [x] Notes persisted in database
- [x] Search/filter notes (optional)

## Technical Notes
- Notes stored in SQLite via Data Logger service
- New table: `notes (id, title, content, created_at, updated_at)`
- API endpoints in Data Logger:
  - GET /api/notes - list all
  - POST /api/notes - create
  - GET /api/notes/{id} - get one
  - PUT /api/notes/{id} - update
  - DELETE /api/notes/{id} - delete
- QML TextArea with basic markdown or HTML support
- Navigation: NotesList.qml, NoteEditor.qml

## Dependencies
- Data Logger service
- Database schema
