## Description

Create a mock camera driver that simulates camera hardware functionality. This driver will provide a fake camera feed and support capturing "photos" for development and testing purposes. The mock will generate placeholder images or use sample images to simulate the camera output.

### Mock Behavior

1. **Camera Feed Simulation**
   - Generate a simple colored rectangle or gradient as fake viewfinder
   - Optionally overlay timestamp or "MOCK CAMERA" watermark
   - Simulate different resolutions (e.g., 640x480, 1280x720, 1920x1080)

2. **Photo Capture**
   - Generate a placeholder image when "capture" is called
   - Options:
     - Solid color with timestamp overlay
     - Random gradient pattern
     - Sample stock images from assets folder
   - Save to designated photos directory with timestamp filename

3. **Camera States**
   - Initialize/start camera
   - Stop/release camera
   - Switch between front/back (simulated)
   - Get camera capabilities (resolution list, etc.)

### HIL Interface

Implement `ICamera` interface following the existing HIL pattern:
- `initialize()` - Start mock camera
- `capture()` - Take a photo, return file path
- `get_preview_frame()` - Return current frame for viewfinder
- `get_status()` - Return camera state
- `set_resolution(width, height)` - Configure output resolution
- `release()` - Stop and cleanup

## Implementation Notes

### Suggested Image Generation

```python
from PIL import Image, ImageDraw, ImageFont
from datetime import datetime

def generate_mock_photo(width: int, height: int) -> Image:
    # Create gradient or solid color
    img = Image.new('RGB', (width, height), color=(73, 109, 137))
    draw = ImageDraw.Draw(img)

    # Add timestamp overlay
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    draw.text((10, 10), f"MOCK CAMERA\n{timestamp}", fill=(255, 255, 255))

    return img
```
