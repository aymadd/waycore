## Description

Show message delivery status in chat UI:

**Status States:**
- ⏳ Sending - message being transmitted
- ✓ Sent - transmitted over radio
- ✓✓ Delivered - ACK received from recipient
- ❌ Failed - transmission failed or timed out

**Implementation:**
- Track ACK responses from mesh network
- Update message status in database
- Show status icon on sent messages
- Retry option for failed messages
