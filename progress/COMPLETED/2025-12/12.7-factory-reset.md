# 12.7 Factory Reset

## Status: COMPLETED
**Started**: 2025-12-25
**Completed**: 2025-12-25

## Description
Add factory reset option to System Settings. This deletes all user data (notes, preferences, logs) and resets the device to default state.

## Acceptance Criteria
- [x] Factory reset button in Settings UI
- [x] Confirmation dialog before reset
- [x] API endpoint to trigger factory reset
- [x] Clears all database tables
- [x] Resets preferences to defaults
- [x] UI feedback during reset process
- [x] Navigates to home after reset

## Technical Notes
- Add POST /api/system/factory-reset to Core Daemon
- Core Daemon calls Data Logger to clear data
- Data Logger clears: notes, events, comms_messages, ai_inferences
- Data Logger resets: user_preferences to defaults
- Consider: confirmation code or double-confirm for safety

## Dependencies
- Settings UI (Phase 11)
- Data Logger service
