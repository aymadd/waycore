# Task: Vision Model Improvement for Outdoor Recognition

**Phase**: Phase 15 - AI App **Task ID**: 15.24 **Status**: COMPLETED **Started**:
2025-12-27 **Completed**: 2025-12-27 **Priority**: Medium

## Description

Improve the vision model accuracy for outdoor/nature use cases by replacing or
augmenting MobileNetV3 (ImageNet-1000) with models trained on nature-specific
datasets. The current model struggles with mushroom, plant, and wildlife
identification because ImageNet has limited outdoor species coverage.

## Current State (Problems)

1. **Limited classes**: MobileNetV3 trained on ImageNet-1000 with generic
   classes
2. **Poor species coverage**: Only ~10 mushroom types, limited wildlife species
3. **Low accuracy**: 0-20% confidence on outdoor photos (mushrooms, deer,
   plants)
4. **No edibility info**: Cannot distinguish edible vs poisonous species

## Target State (Goals)

1. **Domain-specific model**: Use model trained on iNaturalist or similar
2. **High accuracy**: >70% accuracy on common outdoor species
3. **Species coverage**: 1000+ species of plants, fungi, wildlife
4. **Safety-aware**: Flag potentially dangerous species (poisonous, venomous)

## Options to Evaluate

### Option A: iNaturalist Pre-trained Model (Recommended)

- **Model**: EfficientNet-B0 or ResNet-50 trained on iNaturalist 2021
- **Classes**: 10,000 species (plants, animals, fungi, insects)
- **Size**: ~20-50MB (TFLite quantized)
- **Pros**: Ready to use, excellent species coverage
- **Cons**: Larger than current model

### Option B: CLIP for Zero-Shot Classification

- **Model**: CLIP ViT-B/32 or MobileCLIP
- **Approach**: Open vocabulary - classify any text description
- **Size**: ~150MB (quantized)
- **Pros**: Infinitely flexible, can ask "is this edible?"
- **Cons**: Larger model, more complex integration

### Option C: Specialized Ensemble

- **Models**: MobileNetV3 + FungiNet + PlantNet
- **Approach**: Route to specialist model based on initial classification
- **Size**: ~30MB total
- **Pros**: Best accuracy per domain
- **Cons**: Complex, multiple models to maintain

### Option D: Fine-tune on Custom Dataset

- **Base**: EfficientNet-B0 pretrained
- **Dataset**: iNaturalist subset + Fungi + PlantCLEF
- **Size**: ~20MB
- **Pros**: Optimized for Waycore use cases
- **Cons**: Requires training infrastructure, ongoing maintenance

## Model Distribution

Models will be sourced from HuggingFace Hub (see task 15.26), leveraging
existing infrastructure instead of creating a custom repository. This enables:

1. **Existing models**: iNaturalist, CLIP models already on HuggingFace
2. **Built-in caching**: HuggingFace Hub handles download caching
3. **Model profiles**: Config-based selection (basic, nature, full)
4. **Safety metadata**: Bundled with waycore-knowledge releases

### HuggingFace Model Sources

```yaml
# config/models.yaml
models:
  efficientnet_inat:
    source: "huggingface"
    repo_id: "timm/efficientnet_b0.ra_in1k"  # Or iNaturalist-specific
    use_case: "nature"

  mobileclip:
    source: "huggingface"
    repo_id: "apple/MobileCLIP-S1"
    use_case: "zero-shot"
```

### Safety Metadata

Species safety info (edibility, toxicity) bundled with waycore-knowledge:

```
waycore-knowledge releases:
  - knowledge.db
  - knowledge.idx
  - species_safety.json  # Edibility, toxicity metadata
```

## Implementation Notes

### Completed Implementation (2025-12-27)

**Option A Selected**: iNaturalist Pre-trained Model

Implemented a comprehensive iNaturalist model integration following Option A from the
evaluation. The implementation includes:

#### Files Created/Modified:

1. **`device/services/ai_service/models/inaturalist_runner.py`** (NEW)
   - `INaturalistRunner` class for species classification
   - Safety warnings for 40+ dangerous species categories (poisonous fungi, venomous
     snakes, toxic plants)
   - Taxonomy metadata support (kingdom, phylum, class, order, family, genus)
   - Automatic fallback to MobileNetV3 when iNaturalist model unavailable
   - ImageNet-style preprocessing (normalized to [0,1] with standard mean/std)

2. **`device/services/ai_service/models/runtime.py`** (MODIFIED)
   - Added `_create_inaturalist_runner()` factory function
   - Registered "inaturalist" model ID in registry
   - Falls back to MobileNet if iNaturalist model not found

3. **`device/services/ai_service/models/config/models.yaml`** (MODIFIED)
   - Changed default vision model to `inaturalist`
   - Added iNaturalist model configuration with:
     - 10,000 species coverage
     - Safety warnings enabled
     - Taxonomy metadata path
   - Added model profiles (nature, minimal, full)

4. **`scripts/download-models.sh`** (MODIFIED)
   - Added `--nature` flag for downloading iNaturalist labels
   - Integrated Python label downloader script

5. **`scripts/download-inaturalist-labels.py`** (NEW)
   - Downloads iNaturalist 2021 mini dataset labels
   - Creates curated species labels as fallback
   - Generates taxonomy.json for species metadata

6. **Documentation Updated:**
   - `docs/manual/apps/ai-assistant.md` - Added species ID section
   - `docs/models/README.md` - Added iNaturalist model info

#### Safety Categories Implemented:

- **Fungi**: Amanita (death cap), Galerina, Gyromitra, Cortinarius, etc.
- **Plants**: Aconitum (monkshood), Conium (hemlock), Datura, Digitalis, etc.
- **Animals**: Crotalus (rattlesnake), Latrodectus (black widow), etc.

#### Key Design Decisions:

1. **Fallback Architecture**: iNaturalist runner gracefully falls back to MobileNetV3
   if the iNaturalist model file is not present, ensuring the system works OOTB.

2. **Curated Labels**: Rather than requiring a full 10,000 species download, we
   provide a curated list of ~200 most common and dangerous species for quick setup.

3. **Safety-First**: All potentially dangerous species get automatic warnings in
   metadata, which are surfaced in the UI and LLM context.

4. **Model Profiles**: Added config-based profiles (nature, minimal, full) for
   different deployment scenarios.
