## Description

Add dedicated UI for direct (private) messages with individual nodes:

**Features:**
- Tap node to open DM conversation
- Separate conversation view per node
- Show conversation history
- DM badge/indicator on nodes with unread messages
- Encryption indicator for private messages

**UI Flow:**
1. Node list → Tap node → Opens DM conversation
2. Or: Chat → Tap sender name → Opens DM with that node
