## Description

Create detailed node information screen showing all telemetry:

**Node Details:**
- Node ID and names (short/long)
- Hardware model and firmware version
- Battery level with icon
- Signal quality (RSSI/SNR with visual bars)
- Last seen timestamp
- Hop count to reach node

**Position Info (if available):**
- GPS coordinates
- Altitude
- Distance from our device
- Direction/bearing

**Telemetry (if available):**
- Temperature
- Humidity
- Barometric pressure

**Actions:**
- Send direct message button
- Toggle favorite
- View on map (future)
