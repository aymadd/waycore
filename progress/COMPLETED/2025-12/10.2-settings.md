## Description

Implement a Settings screen per the UI plan with sections:

1. System Information (versions, model, uptime, storage)
2. System Actions (reboot/shutdown; wire as stubs initially)
3. Display (brightness slider, timeout)
4. Radio Settings (LoRa, Wi‑Fi; toggles as stubs)
5. Power Settings (mode, battery info)
6. Developer Settings (debug/log level/mock hardware)
7. About (licenses/credits/docs links)

## Deliverables
