## Script Details

### `dev-start.sh`

```bash
#!/bin/bash
# Start Waycore development environment

# 1. Check prerequisites
check_docker
check_poetry

# 2. Start infrastructure
docker compose -f docker/compose/dev.yml up -d mqtt

# 3. Download models if needed
if [ ! -f "$MODEL_PATH/language/phi-3-mini*.gguf" ]; then
    ./scripts/download-models.sh --all
fi

# 4. Start backend services
docker compose -f docker/compose/dev.yml up -d

# 5. Wait for services to be healthy
wait_for_health http://localhost:8010/health

# 6. Start UI (optional, with --ui flag)
if [ "$1" == "--ui" ]; then
    cd device/apps/ui && poetry run python main.py
fi
```

### `dev-stop.sh`

```bash
#!/bin/bash
# Stop all Waycore services
docker compose -f docker/compose/dev.yml down
pkill -f "waycore-ui" 2>/dev/null || true
```

### `dev-status.sh`

```bash
#!/bin/bash
# Show status of all components
echo "=== Docker Services ==="
docker compose -f docker/compose/dev.yml ps

echo "=== Service Health ==="
for port in 8000 8001 8002 8003 8010; do
    curl -s http://localhost:$port/health && echo " :$port OK" || echo " :$port DOWN"
done

echo "=== Models ==="
ls -lh /opt/waycore/models/*/
```
