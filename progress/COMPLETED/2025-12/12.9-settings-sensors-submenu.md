## Description

Implement the Sensors submenu within Settings to display the live status of all hardware sensors. This screen serves as a diagnostic view showing whether each sensor is connected, operational, and providing readings.

### Sensors Displayed

1. **GPS** - Location sensor (latitude, longitude, fix status, satellite count)
2. **Temperature** - Ambient temperature sensor (current reading, status)
3. **Barometer/Pressure** - Atmospheric pressure sensor (hPa, altitude estimation)
4. **Accelerometer** - Motion/orientation sensor (X, Y, Z values, status)
5. **Magnetometer/Compass** - Heading sensor (degrees, calibration status)
6. **Light Sensor** - Ambient light level (lux, status)
7. **Battery** - Battery level, voltage, charging status

### Implementation

- Created SettingsSensors.qml with dynamic sensor list from SensorBridge
- Sensors read from SensorRegistry via backend API
- Status indicators (🟢 Online, 🟡 Calibrating, 🔴 Offline/Error)
- Sensor discovery button to refresh sensor list
- Calibration button for magnetometer when needed
