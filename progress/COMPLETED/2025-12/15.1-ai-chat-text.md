## Implementation Notes

Implemented the AI Chat feature following the existing UI architecture patterns:

### Files Created/Modified:
1. **`device/apps/ui/ai_bridge.py`** - New bridge class for QML-backend communication
   - `AIBridge` QObject with signals: `loadingChanged`, `errorChanged`, `messagesChanged`
   - Slots: `sendChat(question)`, `setModelId(model_id)`, `getModelId()`, `getAvailableModels()`, `clearMessages()`, `getMessages()`
   - Mock responses when backend unavailable
   - Properties: `isLoading`, `error`, `modelId`, `messages`

2. **`device/apps/ui/qml/AIChat.qml`** - Chat UI with:
   - Message list with user/assistant bubbles (role-based styling)
   - Model selector dropdown (ComboBox)
   - Input bar with send button
   - Loading indicator during inference
   - Toast for error messages
   - Clear chat dialog with confirmation
   - Empty state with helpful prompts

   - `chat(question, model_id, context)` method

4. **`device/apps/ui/main.py`** - Registered `AIBridge` as context property

5. **`device/apps/ui/qml/AppShell.qml`** - Added AI navigation route

6. **`device/apps/ui/qml/qmldir`** - Registered AIChat component
