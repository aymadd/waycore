## Description

Create mock mesh network driver that simulates multiple nodes:

**Mock Network Features:**
- Configurable number of simulated peer nodes (default: 3)
- Each node has: ID, name, last seen timestamp, online status
- Simulated message latency (realistic mesh delays)
- Simulated packet loss (configurable %)
- Nodes randomly come online/offline

**Driver Interface:**
- get_nodes(): list of visible nodes
- send_message(node_id, text): send to specific node or broadcast
- receive_messages(): get pending inbound messages
- get_my_node_info(): this device's node identity
