## Example: AI Assistant Manual

```markdown
# AI Assistant

> Your on-device AI companion for outdoor questions, sensor data, and more.

## Overview

The AI Assistant is a conversational interface that can:
- Answer questions about outdoor skills, survival, and navigation
- Read your device's sensor data (temperature, GPS, altitude)
- Help identify plants and animals from photos
- Search your notes and provide contextual help

All processing happens on-device - no internet required.

## Getting Started

1. From the Home screen, tap **AI**
2. Type your question in the text box
3. Tap **Send** or press Enter
4. Wait for the response (may take a few seconds)

## Features

### Text Chat

Ask questions in natural language:
- "What's my current altitude?"
- "How do I start a fire without matches?"
- "What's the best way to find water?"

### Image Analysis

Attach an image to get identification help:
1. Tap the **📷** button to take a photo, or **🖼️** for gallery
2. Add a question like "What plant is this?"
3. Tap Send

⚠️ **Safety Note**: Never eat plants or mushrooms based solely on AI identification. Always verify with an expert.

### Sensor Queries

Ask about your current conditions:
- "What's the temperature?"
- "Where am I?" (GPS coordinates)
- "Which direction am I facing?"
- "How's my battery?"

### Conversation History

- Previous conversations are saved automatically
- Tap **📜** to view past conversations
- Tap **🗑️** to clear current conversation

## Tips

- Keep questions specific for better answers
- The AI works best for factual outdoor/survival topics
- For emergencies, use the SOS feature instead
- Responses may take 5-10 seconds on complex questions

## Troubleshooting

### AI responses are slow
The AI runs on-device which takes processing power. Complex questions take longer. Keep the device cool for best performance.

### "Model not loaded" error
The AI model may need to download on first use. Connect to WiFi and restart the app.

### Generic or unhelpful answers
Try rephrasing your question more specifically. Include context like your activity or goal.

## Related

- [Maps](./maps.md) - For navigation
- [Notes](./notes.md) - Save AI responses as notes
- [Sensors](../features/sensors.md) - Sensor data overview
```

## Cursor Rule Addition

Add to `.cursorrules`:

```markdown
## Software Manual Documentation (MANDATORY)

When making changes to user-facing features, you MUST update the corresponding manual page in `docs/manual/`:

### Trigger Conditions

Update manual documentation when:
- ✅ Adding new user-facing features
- ✅ Changing how existing features work
- ✅ Adding new apps or screens
- ✅ Modifying settings or options
- ✅ Changing keyboard shortcuts or gestures
- ✅ Fixing user-visible bugs (update troubleshooting)

### Update Checklist

1. Find or create the relevant page in `docs/manual/`
2. Update feature descriptions to match implementation
3. Add screenshots or examples if helpful
4. Update troubleshooting if relevant
5. Check cross-references to other pages

### Documentation Style

- Write for non-technical users
- Use step-by-step instructions
- Include tips and common issues
- Keep language simple and clear
```
