# Task: Fix Pre-commit OpenAPI Generation Loop

**Phase**: Phase 14 - Developer Experience
**Task ID**: 14.1
**Status**: COMPLETED
**Started**: 2025-12-26
**Completed**: 2025-12-26

## Description

The pre-commit hooks enter an infinite loop because:

1. **Black/ruff-format** keeps reformatting `scripts/generate-openapi.py`
2. **OpenAPI generation** produces non-deterministic output (different each run)

This prevents normal commits without using `--no-verify`.

## Root Causes

1. The generate-openapi.py script is being reformatted by black on every run
2. OpenAPI specs may have non-deterministic ordering (even with `sort_keys=True`)
3. The hook runs on every commit even when API files haven't changed

## Proposed Solutions

1. **Format the script properly once** and ensure it stays formatted
2. **Add deterministic ordering** to all JSON output
3. **Exclude scripts/ from pre-commit** or configure it properly
4. **Make OpenAPI hook only run when needed** (check file hashes)
