## Description

Create the Camera app UI in QML that provides a viewfinder display and capture functionality. The app connects to the camera service API to display the camera feed (mocked for now) and capture photos. The UI should feel intuitive and responsive, similar to native camera apps.

### UI Components

1. **Viewfinder**
   - Full-screen camera preview area
   - Displays mock feed from camera service
   - Aspect ratio maintained (typically 4:3 or 16:9)

2. **Capture Button**
   - Large, prominent shutter button at bottom center
   - Visual feedback when pressed (animation/flash)
   - Disabled state during capture processing

3. **Controls Overlay**
   - Back button to exit camera
   - Gallery shortcut (thumbnail of last photo)
   - Settings gear icon (optional - for resolution, etc.)

4. **Capture Feedback**
   - Brief white flash or shutter animation on capture
   - Toast notification showing "Photo saved"
   - Thumbnail preview of captured photo briefly

5. **Error States**
   - "Camera unavailable" message if service down
   - "Storage full" warning if applicable

### User Flow

1. User opens Camera app from home grid
2. Viewfinder shows camera feed (mock)
3. User taps shutter button
4. Visual capture feedback (flash/animation)
5. Photo saved, brief thumbnail preview shown
6. User can continue taking photos or exit

### Navigation

- Camera accessible from Home grid (📷 icon)
- Gallery shortcut in camera UI (last photo thumbnail)
- Back button returns to Home

## Implementation Notes

### Mock Viewfinder Display

Since we're mocking, the viewfinder can:
- Display a static placeholder image
- Show a simple animated gradient
- Fetch "preview" frames from the camera service periodically

```qml
// Simple mock viewfinder
Rectangle {
    id: viewfinder
    color: "#1a1a1a"

    // Gradient animation for "live" feel
    Rectangle {
        anchors.fill: parent
        gradient: Gradient {
            GradientStop { position: 0.0; color: "#2a3d33" }
            GradientStop { position: 1.0; color: "#1a2d23" }
        }
    }

    Text {
        anchors.centerIn: parent
        text: "📷 MOCK CAMERA"
        color: "#666"
        font.pixelSize: 24
    }
}
```

### Capture Animation

```qml
// White flash overlay for capture effect
Rectangle {
    id: flashOverlay
    anchors.fill: parent
    color: "white"
    opacity: 0

    SequentialAnimation {
        id: captureAnimation
        PropertyAnimation { target: flashOverlay; property: "opacity"; to: 0.8; duration: 50 }
        PropertyAnimation { target: flashOverlay; property: "opacity"; to: 0; duration: 150 }
    }
}
```
