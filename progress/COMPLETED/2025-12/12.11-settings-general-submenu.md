## Description

Implement the General submenu within Settings containing core device preferences and system controls.

### Settings Sections Implemented

1. **Units**
   - Temperature: Celsius / Fahrenheit
   - Distance: Kilometers / Miles
   - Weight: Kilograms / Pounds
   - Pressure: hPa / inHg / mmHg
   - Time format: 12-hour / 24-hour

2. **Display**
   - Brightness slider (0-100%)
   - Screen timeout dropdown (30s, 1m, 2m, 5m, Never)

3. **Developer Options**
   - Debug mode toggle
   - Theme selection (dark/light)

4. **Storage Usage**
   - Total storage capacity from backend
   - Used storage with breakdown (System, Apps, Data)
   - Visual progress bar showing usage
   - Color coding (green → yellow → red based on %)
   - Refresh Storage Info button

5. **Factory Reset**
   - Warning text about data loss
   - Two-tap confirmation button
   - Progress indicator during reset
   - Clears notes, resets preferences to defaults
