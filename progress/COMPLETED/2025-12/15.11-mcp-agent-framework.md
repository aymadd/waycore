**Phase**: Phase 15 - AI App **Task ID**: 15.11 **Status**: COMPLETED **Started**:

## Description

Implement an agentic AI system using **Anthropic's official MCP Python
framework** to enable the on-device AI to use tools, access context, and perform
actions. This establishes the foundation for all AI tool integrations.

## Current State (Problems)

1. **No agent framework**: AI can only do simple Q&A, no tool use
2. **No MCP integration**: Cannot leverage the MCP ecosystem of tools and
   servers
3. **No structured tool calling**: No standard way for AI to invoke functions
4. **No context injection**: AI has no access to real-time device data

## Target State (Goals)

1. **MCP-compliant agent**: AI service implements MCP client using official
   `mcp` package
2. **Tool registry**: Centralized registry for all available tools via MCP
3. **Agentic loop**: AI can reason, call tools, and incorporate results
4. **Extensible architecture**: Easy to add new tools via MCP servers

## Framework Decision

**Using Anthropic's official MCP Python package (`mcp`)** as our agentic AI
framework.

### Transport Strategy: Hybrid Approach

| Component                           | Transport               | Rationale                                                |
| ----------------------------------- | ----------------------- | -------------------------------------------------------- |
| MCP Servers (sensors, RAG, actions) | `stdio`                 | Run as subprocesses of AI Service, zero network overhead |
| AI Service ↔ UI                     | Existing UDS + HTTP API | Already built, works well                                |
| External tools (future)             | Streamable HTTP         | Standard for remote services                             |

MCP servers start as **child processes** of the AI Service and communicate via
stdio — the simplest, fastest option for local integrations.

## MCP Protocol Overview

The Model Context Protocol provides:

- **Tools**: Functions the AI can call (get_temperature, search_docs, etc.)
- **Resources**: Data sources the AI can read (files, databases)
- **Prompts**: Reusable prompt templates
- **Sampling**: Request completions from the AI

### MCP Message Flow

```
User Query: "What's the temperature outside?"
     │
     ▼
┌─────────────────────────────────────────────────────────────┐
│ Agent Loop                                                   │
│                                                              │
│  1. LLM analyzes query → decides to use get_temperature tool │
│  2. MCP Client sends tools/call to Sensor MCP Server        │
│  3. Server executes tool, returns result                     │
│  4. Agent incorporates result into response                  │
│  5. Return: "The current temperature is 23°C"               │
└─────────────────────────────────────────────────────────────┘
```

```python
# device/services/ai_service/mcp/manager.py
from __future__ import annotations

import asyncio
import logging
from contextlib import asynccontextmanager
from dataclasses import dataclass
from typing import Any, AsyncIterator

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
from mcp.types import Tool

logger = logging.getLogger(__name__)


@dataclass
class MCPServerConfig:
    """Configuration for an MCP server."""

    name: str
    command: str
    args: list[str]
    env: dict[str, str] | None = None
    timeout_seconds: float = 10.0
    requires_confirmation: list[str] | None = None


class MCPManager:
    """Manages MCP server connections via stdio."""

    def __init__(self) -> None:
        self._sessions: dict[str, ClientSession] = {}
        self._tools: dict[str, tuple[str, Tool]] = {}  # tool_name -> (server_name, tool)
        self._server_configs: dict[str, MCPServerConfig] = {}

    async def connect_server(self, config: MCPServerConfig) -> None:
        """Start and connect to an MCP server as subprocess."""
        logger.info(f"Connecting to MCP server: {config.name}")

        params = StdioServerParameters(
            command=config.command,
            args=config.args,
            env=config.env,
        )

        # Start the subprocess and create session
        read, write = await stdio_client(params).__aenter__()
        session = await ClientSession(read, write).__aenter__()

        # Initialize the session
        await session.initialize()

        # Discover available tools
        tools_result = await session.list_tools()
        for tool in tools_result.tools:
            self._tools[tool.name] = (config.name, tool)
            logger.info(f"  Registered tool: {tool.name}")

        self._sessions[config.name] = session
        self._server_configs[config.name] = config

    async def connect_all(self, configs: list[MCPServerConfig]) -> None:
        """Connect to all configured MCP servers."""
        for config in configs:
            try:
                await self.connect_server(config)
            except Exception as e:
                logger.error(f"Failed to connect to {config.name}: {e}")

    def list_tools(self) -> list[Tool]:
        """List all available tools across all servers."""
        return [tool for _, tool in self._tools.values()]

    def get_tool(self, name: str) -> Tool | None:
        """Get a tool by name."""
        if name in self._tools:
            return self._tools[name][1]
        return None

    def requires_confirmation(self, tool_name: str) -> bool:
        """Check if a tool requires user confirmation."""
        if tool_name not in self._tools:
            return False
        server_name, _ = self._tools[tool_name]
        config = self._server_configs.get(server_name)
        if config and config.requires_confirmation:
            return tool_name in config.requires_confirmation
        return False

    def get_timeout(self, tool_name: str) -> float:
        """Get the timeout for a tool's server."""
        if tool_name not in self._tools:
            return 10.0
        server_name, _ = self._tools[tool_name]
        config = self._server_configs.get(server_name)
        return config.timeout_seconds if config else 10.0

    async def call_tool(
        self,
        name: str,
        arguments: dict[str, Any],
    ) -> Any:
        """Call a tool on its MCP server."""
        if name not in self._tools:
            raise ValueError(f"Unknown tool: {name}")

        server_name, _ = self._tools[name]
        session = self._sessions[server_name]
        timeout = self.get_timeout(name)

        try:
            result = await asyncio.wait_for(
                session.call_tool(name, arguments),
                timeout=timeout,
            )
            return result
        except asyncio.TimeoutError:
            raise TimeoutError(f"Tool {name} timed out after {timeout}s")

    async def close_all(self) -> None:
        """Close all MCP server connections."""
        for name, session in self._sessions.items():
            try:
                await session.__aexit__(None, None, None)
                logger.info(f"Closed MCP server: {name}")
            except Exception as e:
                logger.error(f"Error closing {name}: {e}")
        self._sessions.clear()
        self._tools.clear()
```

### Agent Controller

```python
# device/services/ai_service/agent/controller.py
from __future__ import annotations

import json
import logging
from dataclasses import dataclass
from typing import Any, AsyncIterator

from device.services.ai_service.mcp.manager import MCPManager

logger = logging.getLogger(__name__)


@dataclass
class ToolCall:
    """Represents a tool call request from the LLM."""

    name: str
    arguments: dict[str, Any]


@dataclass
class ToolResult:
    """Result from executing a tool."""

    tool: str
    success: bool
    result: Any | None = None
    error: str | None = None


@dataclass
class AgentResponse:
    """Response from the agent."""

    content: str
    tool_calls: list[ToolCall] | None = None
    requires_confirmation: list[ToolCall] | None = None


class AgentController:
    """Controls the agentic AI loop using MCP tools."""

    MAX_ITERATIONS = 5  # Prevent infinite loops

    def __init__(
        self,
        llm_runner: Any,
        mcp_manager: MCPManager,
    ) -> None:
        self.llm = llm_runner
        self.mcp = mcp_manager
        self._pending_confirmations: dict[str, ToolCall] = {}

    def get_tools_for_llm(self) -> list[dict[str, Any]]:
        """Get tool definitions formatted for the LLM."""
        tools = self.mcp.list_tools()
        return [
            {
                "name": tool.name,
                "description": tool.description,
                "parameters": tool.inputSchema,
            }
            for tool in tools
        ]

    async def run(
        self,
        query: str,
        context: dict[str, Any] | None = None,
    ) -> AsyncIterator[AgentResponse]:
        """Run the agent loop, yielding responses and confirmation requests."""
        messages = self._build_initial_messages(query, context)
        tools_schema = self.get_tools_for_llm()

        for iteration in range(self.MAX_ITERATIONS):
            logger.debug(f"Agent iteration {iteration + 1}/{self.MAX_ITERATIONS}")

            # Get LLM response with tool definitions
            response = await self.llm.generate(
                messages,
                tools=tools_schema,
            )

            # Extract any tool calls from response
            tool_calls = self._extract_tool_calls(response)

            if not tool_calls:
                # No tools needed, return final response
                yield AgentResponse(content=response.content)
                return

            # Check for tools requiring confirmation
            needs_confirmation = [
                tc for tc in tool_calls
                if self.mcp.requires_confirmation(tc.name)
            ]
            auto_execute = [
                tc for tc in tool_calls
                if not self.mcp.requires_confirmation(tc.name)
            ]

            # Yield confirmation request if needed
            if needs_confirmation:
                yield AgentResponse(
                    content="I need your permission to proceed.",
                    requires_confirmation=needs_confirmation,
                )
                # Store pending confirmations
                for tc in needs_confirmation:
                    self._pending_confirmations[tc.name] = tc
                return  # Wait for user confirmation

            # Execute tools that don't need confirmation
            tool_results = await self._execute_tools(auto_execute)

            # Add results to context for next iteration
            messages.append({"role": "assistant", "content": response.content})
            messages.append({
                "role": "tool",
                "content": self._format_tool_results(tool_results),
            })

            # Yield intermediate response showing tool execution
            yield AgentResponse(
                content=f"Executed {len(tool_results)} tool(s)...",
                tool_calls=auto_execute,
            )

        yield AgentResponse(
            content="I was unable to complete this request. Please try a simpler question."
        )

    async def confirm_tool(self, tool_name: str) -> ToolResult:
        """Execute a previously pending tool after user confirmation."""
        if tool_name not in self._pending_confirmations:
            return ToolResult(
                tool=tool_name,
                success=False,
                error="No pending confirmation for this tool",
            )

        tool_call = self._pending_confirmations.pop(tool_name)
        results = await self._execute_tools([tool_call])
        return results[0]

    def cancel_tool(self, tool_name: str) -> None:
        """Cancel a pending tool confirmation."""
        self._pending_confirmations.pop(tool_name, None)

    async def _execute_tools(self, tool_calls: list[ToolCall]) -> list[ToolResult]:
        """Execute a list of tool calls via MCP."""
        results = []
        for call in tool_calls:
            try:
                result = await self.mcp.call_tool(call.name, call.arguments)
                results.append(ToolResult(
                    tool=call.name,
                    success=True,
                    result=result.content if hasattr(result, 'content') else result,
                ))
            except TimeoutError as e:
                logger.warning(f"Tool {call.name} timed out")
                results.append(ToolResult(
                    tool=call.name,
                    success=False,
                    error=str(e),
                ))
            except Exception as e:
                logger.error(f"Tool {call.name} failed: {e}")
                results.append(ToolResult(
                    tool=call.name,
                    success=False,
                    error=str(e),
                ))
        return results

    def _build_initial_messages(
        self,
        query: str,
        context: dict[str, Any] | None,
    ) -> list[dict[str, str]]:
        """Build initial message list for LLM."""
        messages = []
        if context:
            messages.append({
                "role": "system",
                "content": f"Current context: {json.dumps(context)}",
            })
        messages.append({"role": "user", "content": query})
        return messages

    def _extract_tool_calls(self, response: Any) -> list[ToolCall]:
        """Extract tool calls from LLM response."""
        # Implementation depends on LLM output format
        # For llama.cpp with grammar, parse JSON tool calls
        if hasattr(response, 'tool_calls') and response.tool_calls:
            return [
                ToolCall(name=tc.name, arguments=tc.arguments)
                for tc in response.tool_calls
            ]
        return []

    def _format_tool_results(self, results: list[ToolResult]) -> str:
        """Format tool results for inclusion in messages."""
        formatted = []
        for r in results:
            if r.success:
                formatted.append(f"[{r.tool}]: {r.result}")
            else:
                formatted.append(f"[{r.tool}] ERROR: {r.error}")
        return "\n".join(formatted)
```

## Tool Timeout Handling

Sensors and external services may hang or respond slowly. Implement timeouts to
prevent blocking:

### Timeout Implementation

```python
import asyncio
from typing import Any


class ToolExecutor:
    """Executes tools with timeout and error handling."""

    DEFAULT_TIMEOUT = 10  # seconds

    async def execute_with_timeout(
        self,
        tool_name: str,
        arguments: dict[str, Any],
        timeout: float | None = None,
    ) -> dict[str, Any]:
        """Execute a tool with timeout protection."""
        timeout = timeout or self.DEFAULT_TIMEOUT

        try:
            result = await asyncio.wait_for(
                self._execute_tool(tool_name, arguments),
                timeout=timeout
            )
            return {"success": True, "result": result}

        except asyncio.TimeoutError:
            logger.warning(f"Tool {tool_name} timed out after {timeout}s")
            return {
                "success": False,
                "error": f"Tool timed out after {timeout} seconds. "
                         f"The {tool_name} operation may still be running."
            }

        except Exception as e:
            logger.error(f"Tool {tool_name} failed: {e}")
            return {"success": False, "error": str(e)}

    async def _execute_tool(
        self,
        tool_name: str,
        arguments: dict[str, Any],
    ) -> Any:
        """Internal tool execution."""
        return await self.tools.call(tool_name, arguments)
```

## Streaming Tool Results

For long-running operations, stream progress updates to the UI:

### Streaming Architecture

### Streaming Implementation

```python
from typing import AsyncIterator


class StreamingToolExecutor:
    """Executes tools with streaming progress updates."""

    async def execute_streaming(
        self,
        tool_name: str,
        arguments: dict[str, Any],
    ) -> AsyncIterator[dict[str, Any]]:
        """Execute a tool and yield progress updates."""

        # Initial status
        yield {
            "type": "status",
            "tool": tool_name,
            "message": f"Starting {tool_name}...",
            "progress": 0.0,
        }

        try:
            # Check if tool supports streaming
            if self._tool_supports_streaming(tool_name):
                async for update in self._stream_tool(tool_name, arguments):
                    yield update
            else:
                # Non-streaming tool - just execute
                yield {
                    "type": "status",
                    "tool": tool_name,
                    "message": "Executing...",
                    "progress": 0.5,
                }
                result = await self._execute_tool(tool_name, arguments)
                yield {
                    "type": "result",
                    "tool": tool_name,
                    "result": result,
                    "progress": 1.0,
                }

        except Exception as e:
            yield {
                "type": "error",
                "tool": tool_name,
                "error": str(e),
            }


# UI bridge for streaming
class AIBridge:
    @Slot(str, "QVariant")
    def executeToolStreaming(self, tool_name: str, params: dict) -> None:
        """Start streaming tool execution."""
        asyncio.create_task(self._stream_to_ui(tool_name, params))

    async def _stream_to_ui(self, tool_name: str, params: dict) -> None:
        async for update in self.executor.execute_streaming(tool_name, params):
            self.toolProgressUpdate.emit(update)
```

## Technical Notes

### Framework Choice: Anthropic's Official MCP Package

**Decision**: Use `mcp` Python package (Anthropic's reference implementation).

**Rationale**:

- Official implementation, well-maintained
- Full protocol compliance out of the box
- Ecosystem compatibility with other MCP tools
- stdio transport is simple and efficient for local subprocesses
- Clean async API that integrates well with our architecture

### Transport: stdio vs HTTP

**Decision**: Use stdio transport for all internal MCP servers.

| Aspect           | stdio                            | HTTP                     |
| ---------------- | -------------------------------- | ------------------------ |
| Latency          | ~1ms                             | ~10-50ms                 |
| Setup complexity | Simple (subprocess)              | Requires port management |
| Resource usage   | Shared process memory            | Separate network stack   |
| Reliability      | Process lifecycle tied to parent | Independent              |
| Use case         | Local/internal servers           | Remote/external services |

### Tool Calling with Local LLMs

Since we use llama.cpp with local models (Phi-3, Llama 3.2), tool calling
requires:

1. **Grammar-constrained output**: Use JSON grammar to ensure valid tool call
   format
2. **System prompt engineering**: Explain available tools and expected format
3. **Fallback parsing**: Handle cases where model output is malformed

```python
# Example tool call format for local LLMs
```
