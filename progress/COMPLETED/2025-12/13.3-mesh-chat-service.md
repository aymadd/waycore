## Description

Create backend service and API endpoints for mesh chat:

**Endpoints:**
- GET `/api/mesh/nodes` - list visible nodes with status
- GET `/api/mesh/messages` - get message history
- POST `/api/mesh/messages` - send new message
- GET `/api/mesh/status` - network status (connected nodes count, etc.)

**Service Responsibilities:**
- Poll mesh driver for new messages
- Store message history in database
- Track node online/offline status
- Publish events via message bus for UI updates
