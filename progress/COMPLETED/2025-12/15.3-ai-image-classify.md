## Implementation Notes

### AIBridge Image Classification Methods

Added two new slots to `device/apps/ui/ai_bridge.py`:

1. **`classifyImage(image_b64)`**: Raw classification - returns results only
   - Sends image to `/api/image/classify` endpoint
   - Returns `{success, results: [{label, confidence}]}` or `{success: false, error}`
   - Uses `mobilenetv3` model by default

2. **`classifyImageAndChat(image_b64)`**: Chat-integrated classification
   - Creates/uses current conversation
   - Adds user message with "📷 [Image for classification]"
   - Adds formatted assistant response with results
   - Auto-titles conversation "🖼️ Image Classification"
   - Persists to database

3. **`_get_mock_image_classification()`**: Mock responses
   - Returns random outdoor/nature labels (Mountain, Tree, Bird, etc.)
   - 3-5 results sorted by confidence
   - 0.5s simulated delay

### UI Changes (AIChat.qml)

- Added 📷 button in input bar (left of text field)
- `classifyMockImage()` function triggers classification
- Uses mock base64 image for MVP testing
- Results display in chat with markdown-style formatting:

  • **Mountain**: 85.0%
