# Task: Fix AI Data Persistence

**Phase**: Phase 15 - AI App
**Task ID**: 15.9
**Status**: COMPLETED
**Started**: 2025-12-26
**Completed**: 2025-12-26

## Description

Fix the issue where conversations, messages, and model information are not being persisted to the database correctly.

## Current Issues

1. **Conversations not saved**: Chat history lost on restart
2. **Messages not persisted**: Individual messages not in DB
3. **Models not registered**: Downloaded models not tracked in `ai_models` table

## Root Causes

1. UI uses local SQLite (`~/.waycore/ai.sqlite3`) separate from backend
2. Model downloads not triggering database registration
3. Possible race conditions in database writes

## Deliverables

- [ ] Verify conversations are saved to database
- [ ] Verify messages are persisted per conversation
- [ ] Register downloaded models in `ai_models` table
- [ ] Add startup model scan to register existing models
- [ ] Test data survives container restart

## Technical Details

### Model Registration on Download

When models are downloaded via script or detected:
1. Scan model directories
2. Insert into `ai_models` table
3. Set first model of each type as active

### Conversation Sync

Options:
1. Have UI call backend API for persistence (preferred)
2. Sync local DB to backend periodically
3. Use shared database file (complex in Docker)
