## Description

Integrate the Camera and Gallery apps into the Home grid and ensure smooth navigation between all camera-related screens. This task focuses on the navigation infrastructure and ensuring all pieces work together seamlessly.

### Integration Points

1. **Home Grid Updates**
   - Camera app tile (📷) - already added
   - Gallery app tile (🖼️) - needs to be added
   - Both apps navigate correctly when tapped

2. **AppShell Navigation**
   - Add Camera screen to navigation stack
   - Add Gallery screen to navigation stack
   - Add PhotoViewer for detail view
   - Handle deep navigation (Camera → Gallery → PhotoViewer → back)

3. **Cross-App Navigation**
   - Camera → Gallery (via thumbnail shortcut)
   - Gallery → Camera (via "take photo" button in empty state)
   - PhotoViewer → back to Gallery

4. **Service Integration**
   - SensorBridge exposes camera/photo methods
   - API client configured for camera service
   - Graceful degradation when service unavailable
