# Task: AI Thinking Indicator (Async Processing)

**Phase**: Phase 15 - AI App
**Task ID**: 15.7
**Status**: COMPLETED
**Started**: 2025-12-26
**Completed**: 2025-12-26

## Description

Add a "Thinking..." indicator while AI is processing to prevent UI freeze. Move AI inference to a background thread to keep UI responsive.

## Problem

Currently, when the AI processes a request:
- The UI freezes due to CPU spike
- User cannot interact with the app
- No visual feedback that processing is happening

## Deliverables

- [ ] Add "Thinking..." message in chat while processing
- [ ] Move AI inference to background thread in AIBridge
- [ ] Add animated typing indicator
- [ ] Keep UI responsive during inference

## Technical Details

### Approach

1. Use Qt's `QThread` or `QThreadPool` for background processing
2. Add a placeholder "Thinking..." message immediately
3. Replace with actual response when complete
4. Add typing animation (3 dots pulsing)

### UI Changes

```qml
// Thinking indicator message
Rectangle {
    visible: isLoading
    // Animated dots: "Thinking..." -> "Thinking.." -> "Thinking."
}
```

### Backend Changes

```python
# Use QThread for async inference
class InferenceWorker(QThread):
    finished = Signal(dict)

    def run(self):
        result = self._client.chat(...)
        self.finished.emit(result)
```

## Acceptance Criteria

- [ ] UI remains responsive during AI inference
- [ ] "Thinking..." indicator shows while processing
- [ ] Smooth transition to actual response
- [ ] Works for both chat and image classification
