# Task: Multimodal Image + Prompt (Visual Q&A)

**Phase**: Phase 15 - AI App **Task ID**: 15.19 **Status**: COMPLETED **Started**:
Not started **Completed**: 2025-12-27 **Priority**: High

## Description

Enhance image classification to support multimodal queries - allowing users to
attach an image AND ask a question about it, rather than just getting
classification labels.

## Current State (Problems)

1. **Classification only**: Image upload triggers automatic ImageNet
   classification
2. **No custom questions**: User cannot ask "What plant is this?" or "Is this
   edible?"
3. **Generic labels**: MobileNetV3 returns ImageNet labels (1000 classes), not
   domain-specific
4. **No context**: Classification doesn't consider user's question or intent

## Target State (Goals)

1. **Visual Q&A**: User attaches image AND types a question
2. **Two-stage pipeline**: Vision model extracts features → LLM answers question
3. **Domain awareness**: Better answers for plants, wildlife, equipment, terrain
4. **Natural interaction**: "What kind of mushroom is this? Is it safe to eat?"

## Use Cases

| User Action                             | Current Behavior          | Target Behavior                                                                        |
| --------------------------------------- | ------------------------- | -------------------------------------------------------------------------------------- |
| Attach plant photo                      | "Daisy: 72%, Flower: 68%" | "This appears to be Oxeye Daisy (Leucanthemum vulgare). Edible but check with expert." |
| Attach + "Is this edible?"              | Not supported             | "This mushroom resembles Amanita genus. DO NOT EAT - potentially toxic."               |
| Attach + "What trail marker is this?"   | Generic label             | "This is a blue blaze marker indicating the main trail continues."                     |
| Attach equipment + "How do I use this?" | "Tool: 45%"               | "This appears to be a fire steel. Strike the rod with the scraper at 45° angle..."     |

## Implementation

### API Endpoint

```python
@app.post("/api/chat/multimodal")
async def chat_multimodal(body: dict[str, Any]) -> AIInferenceResponse:
    question = body.get("question", "").strip()
    image_b64 = body.get("image_b64", "")
    model_id = body.get("model_id", "phi3-mini")

    # Stage 1: Vision analysis (if image provided)
    vision_context = ""
    if image_b64:
        vision_result = await classify_image(image_b64)
        vision_context = format_vision_context(vision_result)

    # Stage 2: LLM with vision context
    prompt = build_multimodal_prompt(question, vision_context)

    return await run_llm_inference(prompt, model_id)
```

### Vision Context Format

```python
def format_vision_context(vision_result: dict) -> str:
    labels = vision_result.get("results", [])
    if not labels:
        return "Image analysis: Unable to identify contents."

    lines = ["Image analysis results:"]
    for r in labels[:5]:
        lines.append(f"- {r['label']}: {r['confidence']*100:.1f}%")

    return "\n".join(lines)
```

## Outdoor-Specific Vision Models

The current MobileNetV3 is trained on ImageNet (1000 general classes). For
better outdoor/survival use cases, we should explore specialized models.

### Research: Domain-Specific Models

| Domain    | Model/Dataset | Source          | Notes                             |
| --------- | ------------- | --------------- | --------------------------------- |
| Plants    | PlantNet      | plantnet.org    | 300K species, API available       |
| Plants    | iNaturalist   | inaturalist.org | Community-trained, broad coverage |
| Mushrooms | FungiCLEF     | imageclef.org   | Competition dataset               |
| Wildlife  | iNaturalist   | inaturalist.org | Animals, insects                  |
| Birds     | eBird/Merlin  | ebird.org       | Bird identification               |

### Recommended Approach

**Phase 1 (MVP)**: Use MobileNetV3 + LLM reasoning

- MobileNetV3 provides basic labels
- Phi-3 uses outdoor knowledge to enhance identification
- Strong safety warnings for edibility questions

**Phase 2 (Enhanced)**: Add specialized TFLite models

- Convert PlantNet or iNaturalist models to TFLite
- Multiple models for different domains
- Model switching based on detected category

### PlantNet Integration Option

```python
# PlantNet has a free API tier
# Could use for online mode, fall back to local for offline

PLANTNET_API = "https://my-api.plantnet.org/v2/identify"

async def identify_plant_online(image_b64: str) -> dict:
    """Use PlantNet API for plant identification."""
    async with httpx.AsyncClient() as client:
        resp = await client.post(
            PLANTNET_API,
            files={"images": base64.b64decode(image_b64)},
            params={"api-key": PLANTNET_KEY}
        )
        return resp.json()
```

### Safety-Critical Categories

For these categories, always include strong warnings:

1. **Mushrooms**: "Many toxic species look similar to edible ones. NEVER eat
   unless verified by expert."
2. **Wild Plants**: "Positively identify before consuming. Some edible plants
   have toxic look-alikes."
3. **Berries**: "Many poisonous berries look similar to edible ones."
4. **Wildlife**: "Keep safe distance. Do not approach."
