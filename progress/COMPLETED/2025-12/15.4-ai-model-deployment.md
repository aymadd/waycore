## Technical Details

### Dependencies

```dockerfile
# For ARM (Raspberry Pi 5)
RUN pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
RUN pip install tflite-runtime

# For x86 development
RUN pip install llama-cpp-python
RUN pip install tensorflow-lite  # or tflite-runtime
```

### Model Paths

```yaml
volumes:

```

### Implementation Pattern

```python
from llama_cpp import Llama

class Phi3Runner(ModelRunner):
    def __init__(self, model_path: str):
        self._llm = Llama(
            model_path=model_path,
            n_ctx=4096,
            n_threads=4,
            n_gpu_layers=0,  # CPU only
        )

    def infer_qa(self, pre: QAPreprocessed) -> list[InferenceResult]:
        response = self._llm.create_chat_completion(...)
        return [InferenceResult(label=response, confidence=1.0)]
```
