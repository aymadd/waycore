## Description

Implement the Info submenu within Settings to display comprehensive device and application information. This screen provides users with detailed system information useful for support, debugging, and verification.

2. **Software Information**

   - Python version
   - Qt version
   - OS version

3. **Network Information**
   - Connection status
   - IP address (placeholder)

4. **Runtime Information**
   - System uptime
   - Backend connection status

### UI Design

- Card-based layout with section headers
- Key-value pairs for information
- Read-only display
- Scrollable content
