## Description

Connect the UI to backend for temperature readings. Implementation:

- Create mock temperature sensor driver in HIL layer
- Core Daemon reads from mock driver and exposes via API
- UI displays temperature from backend with unit conversion

Mock temperature behavior:

- Returns ambient temperature (simulated variation around base value)
- Can optionally read Raspberry Pi CPU temperature as real data point
- Temperature returned in Celsius; unit conversion happens in UI based on user
  preference
