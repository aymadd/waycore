**Status**: TODO **Started**: Not started **Completed**: Not completed

## Description

Connect the UI to the backend for time data. The Raspberry Pi 5 gets time from:

1. NTP (Network Time Protocol) when connected to internet
2. Hardware RTC (Real-Time Clock) module if installed
3. System clock (may drift without NTP/RTC)

For this task:

- Create a time endpoint in an appropriate backend service (Core Daemon)
- Return current system time and timezone info
- UI fetches time from backend instead of local JavaScript Date()
