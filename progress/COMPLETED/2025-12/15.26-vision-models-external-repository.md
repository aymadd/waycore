## Description

Integrate vision model management with HuggingFace Hub instead of creating a
separate external repository. HuggingFace is already used in the project (for
the `all-MiniLM-L6-v2` embedding model) and provides model versioning, caching,
and efficient downloads out of the box.

## Why HuggingFace Instead of Custom Repo

| Feature            | Custom Repo   | HuggingFace Hub      |
| ------------------ | ------------- | -------------------- |
| Model hosting      | Must build    | ✅ Built-in          |
| Versioning         | Must build    | ✅ Built-in          |
| Caching            | Must build    | ✅ Built-in          |
| CDN/Downloads      | GitHub limits | ✅ Optimized         |
| Model cards        | Must build    | ✅ Built-in          |
| Already used       | No            | ✅ Yes (embeddings)  |
| Pre-trained models | Must upload   | ✅ Already available |

Most models we need (iNaturalist, CLIP, MobileNet) are already on HuggingFace.

### Phase 2: Model Loader

Create `device/services/ai_service/vision/model_loader.py`:

```python
from __future__ import annotations

import logging
from pathlib import Path
from typing import Any

import yaml
from huggingface_hub import hf_hub_download, snapshot_download

logger = logging.getLogger(__name__)


class VisionModelLoader:
    """Loads vision models from HuggingFace Hub."""

    def __init__(
        self,
        config_path: Path | None = None,
        cache_dir: Path | None = None,
    ):
        self.config_path = config_path or Path("config/models.yaml")
        self.cache_dir = cache_dir or Path.home() / ".cache" / "waycore" / "models"
        self.config = self._load_config()

    def _load_config(self) -> dict[str, Any]:
        if self.config_path.exists():
            return yaml.safe_load(self.config_path.read_text())
        return {"models": {}, "profiles": {}}

    def download_model(self, model_id: str) -> Path:
        """Download a model from HuggingFace Hub.

        Args:
            model_id: Model identifier from config

        Returns:
            Path to downloaded model file
        """
        model_config = self.config["models"].get(model_id)
        if not model_config:
            raise ValueError(f"Unknown model: {model_id}")

        if model_config["source"] != "huggingface":
            raise ValueError(f"Unsupported source: {model_config['source']}")

        logger.info(f"Downloading {model_config['name']} from HuggingFace...")

        model_path = hf_hub_download(
            repo_id=model_config["repo_id"],
            filename=model_config["filename"],
            cache_dir=str(self.cache_dir),
        )

        return Path(model_path)

    def download_profile(self, profile: str = "basic") -> dict[str, Path]:
        """Download all models in a profile.

        Args:
            profile: Profile name (basic, nature, full)

        Returns:
            Dict mapping model_id to downloaded path
        """
        profile_config = self.config["profiles"].get(profile)
        if not profile_config:
            raise ValueError(f"Unknown profile: {profile}")

        paths = {}
        for model_ref in profile_config["models"]:
            model_id = model_ref["id"] if isinstance(model_ref, dict) else model_ref
            paths[model_id] = self.download_model(model_id)

        return paths

    def get_model_for_context(self, context: str) -> str:
        """Select best available model for a use case.

        Args:
            context: Usage context (general, nature, outdoor, etc.)

        Returns:
            model_id of best available model
        """
        if context in ("outdoor", "nature", "wildlife", "plants", "mushrooms"):
            if self.is_available("efficientnet_inat"):
                return "efficientnet_inat"
        return "mobilenet_v3"

    def is_available(self, model_id: str) -> bool:
        """Check if a model is downloaded and available."""
        model_config = self.config["models"].get(model_id)
        if not model_config:
            return False

        # Check if cached
        try:
            from huggingface_hub import try_to_load_from_cache
            result = try_to_load_from_cache(
                repo_id=model_config["repo_id"],
                filename=model_config["filename"],
            )
            return result is not None
        except Exception:
            return False
```

### Phase 3: Update Model Download Script

Replace `scripts/download-models.sh` with HuggingFace integration:

```bash
#!/bin/bash
# Download AI models using HuggingFace Hub
# Usage: ./scripts/download-models.sh [--profile basic|nature|full]

PROFILE="${1:-basic}"

echo "========================================"
echo "  Waycore Model Downloader"
echo "========================================"
echo ""
echo "Profile: $PROFILE"
echo "Cache: ~/.cache/waycore/models"
echo ""

# Use Python with huggingface_hub
poetry run python -c "
from device.services.ai_service.vision.model_loader import VisionModelLoader

loader = VisionModelLoader()
paths = loader.download_profile('$PROFILE')

for model_id, path in paths.items():
    print(f'✓ {model_id}: {path}')
"
```
