## Description

Refactor the current flat Settings screen into a hierarchical submenu-based architecture. The Settings screen will display four main categories as navigation tiles:

1. **General** - Core device preferences (units, brightness, developer mode, reset, storage)
2. **Controls** - Radio and connectivity toggles (LoRA, WiFi, Bluetooth, LTE)
3. **Sensors** - Live status display for all hardware sensors
4. **Info** - Device and application information

Each category tile will navigate to its dedicated submenu screen. The main Settings screen will show these four options as a grid or list with icons and brief descriptions. This architecture provides a cleaner, more organized settings experience that scales as more features are added.

### UI/UX Considerations
- Main Settings screen should use consistent card/tile design for each category
- Each tile should have an icon, title, and brief subtitle describing the section
- Navigation should use a stack-based approach (push submenu, pop to return)
- Back button in each submenu should return to main Settings
- Consider using different accent colors or icons for each category for visual distinction
