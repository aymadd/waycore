## Description

Create backend endpoint for compass/heading data:
- Core Daemon reads from magnetometer driver
- Exposes `/api/sensors/compass` endpoint
- Returns heading, calibration status, magnetic declination

Endpoint response:
- headingDegrees: 0-360 (magnetic north)
- headingCardinal: "N", "NE", "E", etc.
- calibrated: boolean
- declination: degrees (for true north calculation)
