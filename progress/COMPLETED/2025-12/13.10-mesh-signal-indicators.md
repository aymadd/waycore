## Description

Add visual signal quality indicators throughout the mesh UI:

**Signal Bars Component:**
- 4-bar signal indicator (like cell signal)
- Based on SNR values:
  - 4 bars: SNR > 5 (excellent)
  - 3 bars: SNR > 0 (good)
  - 2 bars: SNR > -5 (fair)
  - 1 bar: SNR > -10 (weak)
  - 0 bars: SNR <= -10 (very weak)
- Color coding: green → yellow → red

**Where to Show:**
- Node list: beside each node
- Chat header: current channel quality
- Node details: with numeric values
- Message bubbles: optional indicator

## Implementation Notes

SNR ranges for LoRa (typical):
- Excellent: > 5 dB
- Good: 0 to 5 dB
- Fair: -5 to 0 dB
- Weak: -10 to -5 dB
- Very Weak: < -10 dB

RSSI typical range: -120 to -50 dBm
