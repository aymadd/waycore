# Task: Backend Battery Integration

**Phase**: Phase 11 - Backend Connectivity & System Settings **Task ID**: 11.2
**Status**: TODO **Started**: Not started **Completed**: Not completed

## Description

Connect the UI to backend for battery status. Since we don't have real battery
hardware:

- Create mock battery driver in HIL layer
- Core Daemon reads from mock driver and exposes via API
- UI displays battery level and charging status from backend

Mock battery behavior:

- Simulates discharge over time (configurable rate)
- Simulates charging when "plugged in" (via API toggle)
- Returns level (0-100), charging state, and estimated time remaining
