## Implementation Notes

### Database Layer

Created `AILocalDatabase` class in `device/apps/ui/ai_bridge.py`:
- Local SQLite database at `~/.waycore/ai.sqlite3`
- Tables: `ai_conversations`, `ai_messages`
- Synchronous SQLite for UI thread compatibility
- WAL mode and foreign key constraints enabled

Also extended `device/libs/database/ai.py` with async methods for backend use:
- `create_conversation()`, `get_conversation()`, `get_all_conversations()`
- `update_conversation()`, `delete_conversation()`, `delete_all_conversations()`
- `add_message()`, `get_messages()`, `clear_messages()`, `get_first_user_message()`

### AIBridge Extensions

New signals:
- `conversationsChanged` - emitted when conversation list changes
- `currentConversationChanged` - emitted when active conversation changes

New properties:
- `currentConversationId` - ID of current conversation (0 if none)

New slots:
- `getConversations()` - get all conversations with message counts
- `newConversation()` - create new conversation and switch to it
- `loadConversation(conversationId)` - load existing conversation
- `deleteConversation(conversationId)` - delete a conversation
- `deleteAllConversations()` - delete all conversations
- `getConversation(conversationId)` - get specific conversation

### UI Components

**AIConversationList.qml**:
- ListView of conversations (most recent first)
- Shows title, message count, relative time
- Delete button with confirmation dialog
- New chat button
- Empty state with CTA
- Signals: `conversationSelected(id)`, `newChatRequested()`

**AIChat.qml** updates:
- History button (📜) to open conversation list
- New chat button (✨) to start fresh conversation
- Tracks `currentConversationId`
- Auto-titles from first user message (max 50 chars)
