## Description

Research and document Meshtastic protocol architecture for our implementation:

**Meshtastic Overview:**
- Open-source mesh networking for LoRa radios
- Decentralized, no infrastructure required
- Encrypted communication (AES-256)
- Range: several kilometers line-of-sight

**Key Concepts:**
- Nodes: devices on the mesh network
- Channels: logical groups for communication (like chat rooms)
- Messages: text with sender, timestamp, acknowledgment
- Positions: GPS location sharing between nodes

**Our Implementation Scope (MVP):**
- Mock mesh network with simulated nodes
- Text messaging between nodes
- Node discovery and status display
- Single channel for simplicity (expand later)
