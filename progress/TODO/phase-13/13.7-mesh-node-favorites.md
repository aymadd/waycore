## Description

Add ability to favorite/bookmark nodes as contacts:

**Features:**
- Star/favorite nodes in node list
- Favorites persist to database
- Custom display name/alias for nodes
- Optional notes per node
- Favorites shown at top of node list

**Database Schema:**
```sql
CREATE TABLE mesh_contacts (
    node_id TEXT PRIMARY KEY,
    alias TEXT,
    notes TEXT,
    is_favorite INTEGER DEFAULT 0,
    created_at TEXT,
    updated_at TEXT
);
```
