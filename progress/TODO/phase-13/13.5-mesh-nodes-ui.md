## Description

Create UI for viewing mesh network nodes:

**Nodes Screen:**
- List of all discovered nodes
- Each node shows: name, ID (short), last seen, online/offline status
- Online nodes at top, sorted by last seen
- Tap node to start direct message (future)

**Node Status Indicators:**
- Green dot: online
- Gray dot: offline
- Yellow dot: recently seen (within 5 min)
