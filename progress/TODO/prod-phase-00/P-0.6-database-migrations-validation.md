### Schema Version Table

Each database should have a version tracking table:

```sql
CREATE TABLE IF NOT EXISTS _schema_version (
    version INTEGER PRIMARY KEY,
    applied_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    description TEXT,
    checksum TEXT
);
```

### Pre-Deployment Validation Script

```bash
#!/bin/bash
# scripts/validate-databases.sh

echo "Validating database schemas..."

# Check schema versions
python -c "
from device.libs.database.migrations import MigrationRunner
from pathlib import Path

databases = ['general', 'mesh', 'ai']
for db in databases:
    runner = MigrationRunner(
        db_path=Path(f'/app/data/{db}.sqlite3'),
        migrations_dir=Path(f'device/libs/database/migrations/{db}')
    )
    pending = runner.get_pending_migrations()
    if pending:
        print(f'ERROR: {db}.sqlite3 has {len(pending)} pending migrations')
        exit(1)
    print(f'OK: {db}.sqlite3 is up to date')
"

echo "All databases validated successfully"
```
