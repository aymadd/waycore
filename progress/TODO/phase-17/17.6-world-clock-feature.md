## Description

Implement the World Clock feature within the Time app. Users can view the current time in multiple timezones simultaneously, useful for coordinating with contacts in different regions or tracking time while traveling.

### Features

1. **Timezone List**
   - Display current time for selected cities/timezones
   - Show city name, current time, and offset from local
   - Indicate day difference (+1 day, -1 day)
   - Auto-update every minute

2. **Add Timezone**
   - Search for city or timezone
   - Common cities quick-select list
   - Show UTC offset for each option
   - Prevent duplicate entries

3. **Manage Timezones**
   - Remove timezone from list
   - Reorder timezones (drag or up/down)
   - Persist selections

4. **Local Time Reference**
   - Always show device's local time at top
   - Highlight current timezone
   - Show UTC offset

5. **Time Comparison**
   - Visual indicator for day/night at each location
   - Relative time display ("3 hours ahead")

### Time Calculation

```javascript
function getTimeInTimezone(offsetHours) {
    var now = new Date()
    var utc = now.getTime() + (now.getTimezoneOffset() * 60000)
    var targetTime = new Date(utc + (offsetHours * 3600000))
    return targetTime
}

function formatTimeWithZone(date, offset) {
    var hours = date.getHours()
    var minutes = date.getMinutes()
    var ampm = hours >= 12 ? 'PM' : 'AM'
    hours = hours % 12 || 12

    return hours + ':' + pad(minutes) + ' ' + ampm
}

function getDayDifference(localDate, targetDate) {
    var localDay = localDate.getDate()
    var targetDay = targetDate.getDate()

    if (targetDay > localDay) return "+1"
    if (targetDay < localDay) return "-1"
    return ""
}
```
