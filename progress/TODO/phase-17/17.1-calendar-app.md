## Description

Create a simple calendar app for viewing dates and weekdays. This is a read-only calendar without event creation, reminders, or scheduling features. The purpose is to provide a quick reference for dates while in the field, similar to a traditional paper calendar.

### Features

1. **Month View**
   - Display current month in a traditional grid layout (7 columns for days)
   - Show day numbers with weekday headers (Sun-Sat or Mon-Sun based on locale)
   - Highlight current day
   - Navigate to previous/next months

2. **Year View** (optional)
   - Quick year overview showing all 12 months
   - Tap a month to navigate to month view

3. **Date Information**
   - Display selected date with full weekday name
   - Show week number (optional)
   - Days remaining in month/year (optional)

### UI Design

The calendar should be clean and readable at a glance:
- Large day numbers for easy reading outdoors
- Clear distinction between current day and other days
- Muted styling for days outside current month
- Weekend days visually differentiated (optional)
- Navigation arrows or swipe gestures for month navigation

### No Backend Required

This is a purely frontend feature using JavaScript/QML date functions:
- `Date()` object for current date
- Month/year calculations done locally
- No API calls or database storage needed

## Implementation Notes

### Month Grid Generation

```javascript
// QML/JavaScript date handling
function getDaysInMonth(year, month) {
    return new Date(year, month + 1, 0).getDate();
}

function getFirstDayOfMonth(year, month) {
    return new Date(year, month, 1).getDay(); // 0 = Sunday
}

function generateMonthGrid(year, month) {
    var days = [];
    var daysInMonth = getDaysInMonth(year, month);
    var firstDay = getFirstDayOfMonth(year, month);

    // Previous month padding
    var prevMonth = month === 0 ? 11 : month - 1;
    var prevYear = month === 0 ? year - 1 : year;
    var daysInPrevMonth = getDaysInMonth(prevYear, prevMonth);

    for (var i = firstDay - 1; i >= 0; i--) {
        days.push({ day: daysInPrevMonth - i, currentMonth: false });
    }

    // Current month
    for (var d = 1; d <= daysInMonth; d++) {
        days.push({ day: d, currentMonth: true });
    }

    // Next month padding (to fill 6 rows × 7 days = 42 cells)
    var remaining = 42 - days.length;
    for (var n = 1; n <= remaining; n++) {
        days.push({ day: n, currentMonth: false });
    }

    return days;
}
```

### QML Calendar Grid

```qml
GridView {
    id: calendarGrid
    cellWidth: width / 7
    cellHeight: cellWidth

    model: calendarModel

    delegate: Rectangle {
        width: calendarGrid.cellWidth
        height: calendarGrid.cellHeight
        color: isToday ? App.Theme.primary : "transparent"

        Text {
            anchors.centerIn: parent
            text: model.day
            color: model.currentMonth ? App.Theme.textPrimary : App.Theme.textDisabled
            font.bold: isToday
        }
    }
}
```
