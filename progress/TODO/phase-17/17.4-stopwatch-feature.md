## Description

Implement the Stopwatch feature within the Time app. A simple elapsed time counter that can be started, stopped, and reset. Includes lap time functionality to record splits during timing.

### Features

1. **Stopwatch Display**
   - Large elapsed time display (MM:SS.ms)
   - Millisecond precision (update every 10-100ms)
   - Clean, readable monospace font

2. **Controls**
   - Start button to begin counting
   - Stop/Pause button to halt (preserves time)
   - Reset button to clear to 00:00.00
   - Lap button to record current time (while running)

3. **Lap Times**
   - Record lap/split times
   - Display list of recorded laps
   - Show lap number, lap time, and total time
   - Highlight fastest and slowest laps (optional)
   - Clear laps on reset

4. **Background Operation**
   - Stopwatch continues when navigating away
   - State preserved across tab switches

## Implementation Notes

### Stopwatch Timer

```qml
Timer {
    id: stopwatch
    interval: 10  // 10ms for smooth display
    repeat: true
    running: false

    property int elapsedMs: 0

    onTriggered: {
        elapsedMs += interval
    }
}

property var laps: []

function formatTime(ms) {
    var minutes = Math.floor(ms / 60000)
    var seconds = Math.floor((ms % 60000) / 1000)
    var centis = Math.floor((ms % 1000) / 10)
    return pad(minutes) + ":" + pad(seconds) + "." + pad(centis)
}

function recordLap() {
    var lapTime = laps.length > 0
        ? stopwatch.elapsedMs - laps[laps.length - 1].totalMs
        : stopwatch.elapsedMs
    laps.push({
        lap: laps.length + 1,
        lapMs: lapTime,
        totalMs: stopwatch.elapsedMs
    })
}
```
