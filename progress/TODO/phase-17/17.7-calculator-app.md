## Description

Create a calculator app for performing basic arithmetic operations. This is a standard calculator with essential functions for quick field calculations - distances, conversions, measurements, or any numerical task.

### Features

1. **Basic Operations**
   - Addition (+)
   - Subtraction (−)
   - Multiplication (×)
   - Division (÷)
   - Clear (C) and Clear Entry (CE)
   - Backspace/Delete last digit

2. **Display**
   - Large number display for readability outdoors
   - Show current input and result
   - Decimal point support
   - Negative numbers support (+/−)

3. **Additional Functions** (optional)
   - Percentage (%)
   - Memory functions (M+, M−, MR, MC)
   - Last answer recall (ANS)

4. **Unit Conversion Mode**
   - Temperature: °F ↔ °C (Fahrenheit to Celsius)
   - Distance: km ↔ mi (kilometers to miles)
   - Distance: m ↔ ft (meters to feet)
   - Weight: kg ↔ lb (kilograms to pounds)
   - Volume: L ↔ gal (liters to gallons)
   - Speed: km/h ↔ mph
   - Toggle between calculator and converter modes

### UI Design

The calculator should be functional and easy to use:
- Large buttons for touch accuracy
- Clear visual feedback on button press
- High contrast display for outdoor visibility
- Standard calculator layout (4×5 or 4×6 grid)
- Responsive button grid that adapts to screen size

## Implementation Notes

### Calculator Logic

```javascript
// QML/JavaScript calculator state
property string currentValue: "0"
property string storedValue: ""
property string pendingOperation: ""
property bool newNumber: true

function inputDigit(digit) {
    if (newNumber) {
        currentValue = digit;
        newNumber = false;
    } else {
        if (currentValue === "0" && digit !== ".") {
            currentValue = digit;
        } else {
            currentValue += digit;
        }
    }
}

function inputOperation(op) {
    if (storedValue !== "" && !newNumber) {
        calculate();
    }
    storedValue = currentValue;
    pendingOperation = op;
    newNumber = true;
}

function calculate() {
    if (storedValue === "" || pendingOperation === "") return;

    var a = parseFloat(storedValue);
    var b = parseFloat(currentValue);
    var result;

    switch (pendingOperation) {
        case "+": result = a + b; break;
        case "-": result = a - b; break;
        case "*": result = a * b; break;
        case "/":
            if (b === 0) {
                currentValue = "Error";
                return;
            }
            result = a / b;
            break;
    }

    currentValue = String(result);
    storedValue = "";
    pendingOperation = "";
    newNumber = true;
}

function clear() {
    currentValue = "0";
    storedValue = "";
    pendingOperation = "";
    newNumber = true;
}
```

### Unit Conversion Functions

```javascript
// Temperature
function fahrenheitToCelsius(f) { return (f - 32) * 5 / 9; }
function celsiusToFahrenheit(c) { return c * 9 / 5 + 32; }

// Distance
function kmToMiles(km) { return km * 0.621371; }
function milesToKm(mi) { return mi * 1.60934; }
function metersToFeet(m) { return m * 3.28084; }
function feetToMeters(ft) { return ft * 0.3048; }

// Weight
function kgToLb(kg) { return kg * 2.20462; }
function lbToKg(lb) { return lb * 0.453592; }

// Volume
function litersToGallons(l) { return l * 0.264172; }
function gallonsToLiters(gal) { return gal * 3.78541; }

// Speed
function kmhToMph(kmh) { return kmh * 0.621371; }
function mphToKmh(mph) { return mph * 1.60934; }
```

                anchors.centerIn: parent
                text: modelData
                font.pixelSize: 24
                color: App.Theme.textPrimary
            }

            MouseArea {
                anchors.fill: parent
                onClicked: handleButton(modelData)
            }
        }
    }
}
