## Description

Design and implement the foundational architecture for the Time app, which will house multiple time-related tools: Timer, Stopwatch, Alarms, and World Clock. This task establishes the app structure, navigation between sub-features, and shared components.

### App Structure

The Time app will use a tabbed or segmented interface to switch between features:

```
┌─────────────────────────────────┐
│ ⏱️ Time                    [X] │
├─────────────────────────────────┤
│ [Timer] [Stopwatch] [Alarm] [🌍]│
├─────────────────────────────────┤
│                                 │
│      {Active Feature View}      │
│                                 │
└─────────────────────────────────┘
```

### Shared Components

1. **Time Display** - Large digital time display component
2. **Duration Picker** - Scroll wheels or input for hours:minutes:seconds
3. **Time Button** - Start/Stop/Reset button styling
4. **Progress Ring** - Circular progress indicator for timer/stopwatch

### Navigation

- Time app accessible from Home grid (⏱️ icon)
- Tab bar or segmented control for feature switching
- State preserved when switching between tabs
- Back button returns to Home

### State Management

Time-related features need persistent state:
- Active timers continue in background
- Stopwatch keeps running when navigating away
- Alarms stored in database for persistence

## Implementation Notes

### Tab Bar Component

```qml
Row {
    id: tabBar
    anchors.horizontalCenter: parent.horizontalCenter
    spacing: App.Theme.spacingSmall

    Repeater {
        model: ["Timer", "Stopwatch", "Alarm", "World"]

        Rectangle {
            width: 80
            height: 36
            radius: 18
            color: tabIndex === index ? App.Theme.primary : App.Theme.surface

            Text {
                anchors.centerIn: parent
                text: modelData
                color: tabIndex === index ? App.Theme.textPrimary : App.Theme.textSecondary
            }

            MouseArea {
                anchors.fill: parent
                onClicked: tabIndex = index
            }
        }
    }
}
```

### Shared Time Display

```qml
// TimeDisplay.qml
Item {
    property int hours: 0
    property int minutes: 0
    property int seconds: 0
    property int milliseconds: 0
    property bool showMillis: false

    Text {
        text: {
            var t = pad(hours) + ":" + pad(minutes) + ":" + pad(seconds)
            if (showMillis) t += "." + pad(Math.floor(milliseconds / 10), 2)
            return t
        }
        font.pixelSize: 64
        font.family: "monospace"
        color: App.Theme.textPrimary
    }

    function pad(n, width = 2) {
        return String(n).padStart(width, '0')
    }
}
```
