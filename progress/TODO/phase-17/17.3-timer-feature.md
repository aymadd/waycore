## Description

Implement the Timer feature within the Time app. Users can set a countdown timer for a specific duration, start/pause/reset it, and receive a notification when the timer completes. Multiple timers may be supported in future iterations, but v1 focuses on a single timer.

### Features

1. **Duration Setting**
   - Set hours, minutes, seconds via picker
   - Quick presets (1 min, 5 min, 10 min, 30 min, 1 hour)
   - Remember last used duration

2. **Timer Controls**
   - Start button to begin countdown
   - Pause/Resume toggle during countdown
   - Reset button to clear and return to duration setting
   - Cancel to stop and dismiss

3. **Timer Display**
   - Large countdown display (HH:MM:SS)
   - Visual progress ring showing remaining time
   - Color change when approaching zero (optional)

4. **Timer Completion**
   - Audio alert when timer reaches zero
   - Visual notification (flash, vibrate if available)
   - Dismiss button to stop alert
   - Option to restart same timer

5. **Background Operation**
   - Timer continues when navigating away
   - Timer continues when screen is off
   - Notification shown when timer completes

## Implementation Notes

### Timer Logic

```qml
Timer {
    id: countdownTimer
    interval: 1000
    repeat: true
    running: false

    property int remainingSeconds: 0

    onTriggered: {
        remainingSeconds--
        if (remainingSeconds <= 0) {
            running = false
            timerCompleted()
        }
    }
}

function startTimer(durationSeconds) {
    countdownTimer.remainingSeconds = durationSeconds
    countdownTimer.running = true
}

function pauseTimer() {
    countdownTimer.running = false
}

function resumeTimer() {
    countdownTimer.running = true
}

function resetTimer() {
    countdownTimer.running = false
    countdownTimer.remainingSeconds = 0
}
```

### Progress Ring Calculation

```qml
ProgressRing {
    progress: 1.0 - (countdownTimer.remainingSeconds / totalDurationSeconds)
    // progress goes from 0.0 to 1.0 as timer counts down
}
```
