## Description

Implement the Alarms feature within the Time app. Users can create, edit, enable/disable, and delete alarms. Alarms trigger at the specified time with audio/visual alerts and can repeat on selected days of the week.

### Features

1. **Alarm List**
   - Display all configured alarms
   - Show time, label, repeat days, enabled status
   - Toggle switch to enable/disable each alarm
   - Tap to edit, swipe to delete

2. **Create/Edit Alarm**
   - Time picker (hours:minutes, 12/24 hour format)
   - Label/name input (optional)
   - Repeat days selection (M T W T F S S)
   - Sound selection (future enhancement)
   - Save/Cancel actions

3. **Alarm Trigger**
   - Audio alert when alarm time reached
   - Visual notification/overlay
   - Dismiss button to stop alarm
   - Snooze button (delay 5/10 minutes)

4. **Persistence**
   - Alarms saved to database
   - Survive app restart and device reboot
   - Background service monitors alarm times

5. **Next Alarm Display**
   - Show time until next alarm on main view
   - "No alarms set" when list is empty

### Database Schema

```sql
CREATE TABLE alarms (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    hour INTEGER NOT NULL,
    minute INTEGER NOT NULL,
    label TEXT,
    repeat_days TEXT,  -- JSON array: [0,1,2,3,4] for M-F
    enabled INTEGER DEFAULT 1,
    snooze_minutes INTEGER DEFAULT 10,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## Implementation Notes

### Alarm Manager

```python
class AlarmManager:
    def __init__(self, db: Database):
        self.db = db
        self.active_alarm: int | None = None

    async def check_alarms(self) -> Alarm | None:
        """Check if any alarm should trigger now."""
        now = datetime.now()
        alarms = await self.db.get_enabled_alarms()

        for alarm in alarms:
            if self._should_trigger(alarm, now):
                return alarm
        return None

    def _should_trigger(self, alarm: Alarm, now: datetime) -> bool:
        if alarm.hour != now.hour or alarm.minute != now.minute:
            return False
        if alarm.repeat_days:
            return now.weekday() in alarm.repeat_days
        return True
```
