# Task: Core UI Component Library

**Phase**: Phase 18 - Modular App Ecosystem
**Task ID**: 18.3
**Status**: TODO
**Started**: Not started
**Completed**: Not completed
**Priority**: High

## Description

Extract and enhance the shared UI component library that all apps will use. Move components from `device/apps/ui/qml/components/` to `device/apps/core/qml/components/` and ensure they are properly documented, tested, and follow the design system.

## Context

Currently, UI components live in `device/apps/ui/qml/components/`. For the modular app architecture, these need to be part of the core framework so apps can import them independently. We'll also enhance components for better power efficiency (OLED-friendly dark theme) and field usability.

## AppTile Component

```qml
import QtQuick 2.15

Rectangle {
    id: tile

    property string appId: ""
    property string appName: ""
    property string appIcon: ""
    property bool isEmergency: false

    signal clicked()

    width: Theme.appTileSize
    height: Theme.appTileSize
    radius: Theme.borderRadiusLarge

    color: isEmergency ? Theme.emergency : Theme.surfaceElevated
    border.color: Theme.primaryLight
    border.width: 1

    Column {
        anchors.centerIn: parent
        spacing: Theme.spacingSmall

        Text {
            anchors.horizontalCenter: parent.horizontalCenter
            text: appIcon
            font.pixelSize: Theme.iconSizeXL
        }

        Text {
            anchors.horizontalCenter: parent.horizontalCenter
            text: appName.toUpperCase()
            color: Theme.textPrimary
            font.pixelSize: Theme.labelSize
            font.weight: Theme.fontWeightBold
            font.letterSpacing: 1
        }
    }

    MouseArea {
        anchors.fill: parent
        onClicked: tile.clicked()
        onPressed: tile.scale = 0.95
        onReleased: tile.scale = 1.0
    }

    Behavior on scale {
        NumberAnimation { duration: Theme.animationFast }
    }
}
```
