## Description

Migrate the Compass app to the new modular structure as the first proof-of-concept. This establishes the pattern and validates the architecture before migrating other apps.

## Context

The Compass app is a good first candidate because:
1. It's relatively simple (single screen, few features)
2. It has clear sensor dependencies (magnetometer, optionally GPS)
3. It doesn't have backend complexity
4. It's already functional and can be compared before/after

## Migration Steps

### 1. Create App Directory Structure

```bash
mkdir -p device/apps/compass/qml
mkdir -p device/apps/compass/assets
```

### 2. Create Manifest

Create `device/apps/compass/manifest.json` with the content above.

### 3. Migrate QML

Copy `device/apps/ui/qml/Compass.qml` to `device/apps/compass/qml/CompassMain.qml` and update imports:

**Before**:
```qml
import QtQuick 2.15
import "." as App
import "components" as UI
```

**After**:
```qml
import QtQuick 2.15
import "../../core/qml" as Core
import "../../core/qml/components" as UI
```

### 4. Update App Entry

The app should expose a standard interface that the shell can use:

```qml
// CompassMain.qml
import QtQuick 2.15
import "../../core/qml" as Core
import "../../core/qml/components" as UI

Rectangle {
    id: root
    color: Core.Theme.background

    // Standard app signals
    signal closeRequested()

    // Standard app properties
    property string appId: "com.waycore.compass"
    property string appTitle: "Compass"

    // ... existing compass implementation ...

    // Back button handling
    UI.AppBar {
        id: appBar
        title: root.appTitle
        showBackButton: true
        onBackClicked: root.closeRequested()
    }
}
```

### 5. Update Shell Integration

Modify AppShell.qml to use the app loader:

```qml
function navigateTo(appName) {
    // Check if app is in registry
    var appId = AppBridge.getAppIdByName(appName)
    if (appId) {
        var entry = AppBridge.getAppEntry(appId)
        if (entry) {
            var component = Qt.createComponent(entry)
            if (component.status === Component.Ready) {
                var appInstance = component.createObject(null)
                appInstance.closeRequested.connect(navigateBack)
                router.push(appInstance)
                return
            }
        }
    }

    // Fallback to old switch statement for unmigrated apps
    switch (appName) {
        // ... existing cases ...
    }
}
```

### 6. Sensor Access Pattern

Document how the app accesses sensors:

```qml
// Access sensor data via SensorBridge (already a context property)
Connections {
    target: SensorBridge

    function onMagnetometerUpdated(heading, declination) {
        compass.heading = heading
        compass.declination = declination
    }
}

Component.onCompleted: {
    // Request sensor subscription
    SensorBridge.subscribeMagnetometer()
}

Component.onDestruction: {
    // Clean up sensor subscription
    SensorBridge.unsubscribeMagnetometer()
}
```
