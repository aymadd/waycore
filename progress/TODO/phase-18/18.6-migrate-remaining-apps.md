## Migration Checklist Per App

For each app, complete these steps:

### 1. Create Directory Structure
```bash
mkdir -p device/apps/{app}/qml
mkdir -p device/apps/{app}/backend  # if has backend
```

### 2. Create Manifest
```json
{
  "id": "com.waycore.{app}",
  "name": "{AppName}",
  "version": "1.0.0",
  "icon": "{emoji}",
  "category": "{category}",
  "entry": {
    "qml": "qml/{App}Main.qml",
    "backend": "backend/service.py"  // optional
  },
  "tier": 1 or 2,
  "enabled": true
}
```

### 3. Migrate QML Files
- Copy QML files to new location
- Update imports:
  - `import "." as App` → `import "../../core/qml" as Core`
  - `import "components" as UI` → `import "../../core/qml/components" as UI`
- Update Theme references: `App.Theme.` → `Core.Theme.`
- Add `closeRequested` signal for back navigation

### 4. Migrate Backend (if applicable)
- Move bridge code to `backend/service.py`
- Add `create_bridge()` factory function
- Update imports for new location

### 5. Update AppShell
- Remove old Component definitions
- Add dynamic loading via AppBridge

### 6. Test
- App appears in home grid
- App launches successfully
- All features work
- Back navigation works
