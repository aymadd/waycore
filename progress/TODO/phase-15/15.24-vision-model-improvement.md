# Task: Vision Model Improvement for Outdoor Recognition

Not started **Completed**: Not completed **Priority**: Medium

## Description

Improve the vision model accuracy for outdoor/nature use cases by replacing or
augmenting MobileNetV3 (ImageNet-1000) with models trained on nature-specific
datasets. The current model struggles with mushroom, plant, and wildlife
identification because ImageNet has limited outdoor species coverage.

## Current State (Problems)

1. **Limited classes**: MobileNetV3 trained on ImageNet-1000 with generic classes
2. **Poor species coverage**: Only ~10 mushroom types, limited wildlife species
3. **Low accuracy**: 0-20% confidence on outdoor photos (mushrooms, deer, plants)
4. **No edibility info**: Cannot distinguish edible vs poisonous species

## Target State (Goals)

1. **Domain-specific model**: Use model trained on iNaturalist or similar
2. **High accuracy**: >70% accuracy on common outdoor species
3. **Species coverage**: 1000+ species of plants, fungi, wildlife
4. **Safety-aware**: Flag potentially dangerous species (poisonous, venomous)

## Options to Evaluate

### Option A: iNaturalist Pre-trained Model (Recommended)
- **Model**: EfficientNet-B0 or ResNet-50 trained on iNaturalist 2021
- **Classes**: 10,000 species (plants, animals, fungi, insects)
- **Size**: ~20-50MB (TFLite quantized)
- **Pros**: Ready to use, excellent species coverage
- **Cons**: Larger than current model

### Option B: CLIP for Zero-Shot Classification
- **Model**: CLIP ViT-B/32 or MobileCLIP
- **Approach**: Open vocabulary - classify any text description
- **Size**: ~150MB (quantized)
- **Pros**: Infinitely flexible, can ask "is this edible?"
- **Cons**: Larger model, more complex integration

### Option C: Specialized Ensemble
- **Models**: MobileNetV3 + FungiNet + PlantNet
- **Approach**: Route to specialist model based on initial classification
- **Size**: ~30MB total
- **Pros**: Best accuracy per domain
- **Cons**: Complex, multiple models to maintain

### Option D: Fine-tune on Custom Dataset
- **Base**: EfficientNet-B0 pretrained
- **Dataset**: iNaturalist subset + Fungi + PlantCLEF
- **Size**: ~20MB
- **Pros**: Optimized for Waycore use cases
- **Cons**: Requires training infrastructure, ongoing maintenance

## Recommended Datasets

| Dataset | Images | Species | Use Case |
