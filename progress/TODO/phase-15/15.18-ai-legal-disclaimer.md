## Description

Add legal disclaimers and safety notices for the AI assistant to protect users and clarify that AI outputs should not be blindly trusted, especially for survival-critical decisions.

## Current State (Problems)

1. **No disclaimers**: Users may over-trust AI responses
2. **Liability risk**: No clear statement that AI can make mistakes
3. **Safety concern**: Survival/medical advice could be dangerous if wrong
4. **No user acknowledgment**: Users haven't agreed to terms of use

## Target State (Goals)

1. **Clear disclaimers**: Users understand AI limitations
2. **First-use acknowledgment**: Users must accept terms before using AI
3. **In-context warnings**: Critical topics show inline safety notices
4. **Liability protection**: Clear "use at your own risk" language

### Inline Warning Detection

```python
# device/services/ai_service/safety/topic_detector.py
from __future__ import annotations

import re

CRITICAL_TOPICS = {
    "plant_identification": {
        "keywords": ["edible", "eat", "mushroom", "berry", "forage", "poisonous", "toxic"],
        "warning": "⚠️ NEVER consume plants based solely on AI identification. Misidentification can be fatal. Consult local experts.",
    },
    "medical": {
        "keywords": ["first aid", "injury", "bleeding", "broken", "bite", "sting", "hypothermia", "heat stroke"],
        "warning": "⚠️ This is general information only. Seek professional medical help when possible. Call emergency services for serious injuries.",
    },
    "navigation": {
        "keywords": ["lost", "navigate", "direction", "trail", "route", "rescue"],
        "warning": "⚠️ AI navigation suggestions should be verified. Use proper maps and compass. Stay on marked trails when possible.",
    },
    "survival": {
        "keywords": ["survive", "emergency", "stranded", "water source", "shelter"],
        "warning": "⚠️ Survival situations are serious. Follow established protocols. Activate SOS for emergencies.",
    },
}


def detect_critical_topic(text: str) -> str | None:
    """Detect if text contains critical topics requiring warnings."""
    text_lower = text.lower()

    for topic, config in CRITICAL_TOPICS.items():
        for keyword in config["keywords"]:
            if keyword in text_lower:
                return config["warning"]

    return None


def add_safety_warning(response: str, query: str) -> str:
    """Add safety warning to response if critical topic detected."""
    warning = detect_critical_topic(query) or detect_critical_topic(response)

    if warning:
        return f"{warning}\n\n{response}"

    return response
```

    version = settings.get("ai_disclaimer_version", "")
    return accepted and version == CURRENT_DISCLAIMER_VERSION

CURRENT_DISCLAIMER_VERSION = "1.0"
