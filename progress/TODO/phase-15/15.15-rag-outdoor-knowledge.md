## Description

Create a RAG-indexed knowledge base of survival, outdoor, and tactical
information that the AI can use to provide expert-level guidance on wilderness
skills, emergency situations, and outdoor activities.

## Current State (Problems)

1. **Limited knowledge**: AI has general knowledge but lacks specialist outdoor
   expertise
2. **No local resources**: Cannot work offline with specialized content
3. **Generic advice**: Answers lack depth for survival/tactical scenarios
4. **No regional data**: No knowledge of local plants, wildlife, regulations

## Target State (Goals)

1. **Expert knowledge**: AI can provide detailed survival, hunting, foraging
   guidance
2. **Offline-first**: All knowledge available without internet
3. **Safety-focused**: Always includes safety warnings and caveats
4. **Extensible**: Users can add their own knowledge sources

## Vector Store & Data Structure Selection

Given the hardware constraints (Raspberry Pi 5, 4GB RAM, ARM64), we need a
lightweight, efficient vector store that works well offline.

### Hardware Constraints

| Constraint | Value                 | Impact                         |
| ---------- | --------------------- | ------------------------------ |
| RAM        | 4GB (shared with LLM) | Max ~500MB for vector store    |
| CPU        | ARM Cortex-A76        | No AVX/SSE, need ARM-optimized |
| Storage    | SD card / eMMC        | Prefer sequential reads        |
| Startup    | < 5 seconds           | Index must load quickly        |
| Search     | < 200ms               | Real-time response needed      |

### Vector Store Options Comparison

| Option            | Memory | Startup | Search    | ARM Support    | Complexity |
| ----------------- | ------ | ------- | --------- | -------------- | ---------- |
| **SQLite + FTS5** | Low    | Fast    | Good      | ✅ Native      | Low        |
| **Hnswlib**       | Medium | Fast    | Excellent | ✅ Good        | Medium     |
| ChromaDB          | High   | Slow    | Good      | ⚠️ Heavy deps   | High       |
| FAISS             | Medium | Medium  | Excellent | ⚠️ Build issues | High       |
| LanceDB           | Medium | Fast    | Excellent | ⚠️ New          | Medium     |

### Recommended Approach: Hybrid SQLite + Hnswlib

**Primary: SQLite with FTS5** (Full-Text Search)

- Built into Python, zero dependencies
- Excellent for keyword/phrase matching
- Handles metadata filtering (category, safety level)
- ~50MB for 10K entries
- Instant startup

**Secondary: Hnswlib** (Semantic Search)

- Lightweight C++ library with Python bindings
- ~100MB for 10K 384-dim embeddings
- Sub-10ms search latency
- ARM64 compatible (compiles from source)

### Implementation

```python
from __future__ import annotations

import sqlite3
from pathlib import Path
from typing import Any

import hnswlib
import numpy as np


class OutdoorKnowledgeStore:
    """Hybrid SQLite + Hnswlib store for outdoor knowledge."""

    EMBEDDING_DIM = 384  # all-MiniLM-L6-v2 dimension
    MAX_ELEMENTS = 20000
    EF_CONSTRUCTION = 100
    M = 16

    def __init__(self, data_dir: Path) -> None:
        self.data_dir = data_dir
        self.db_path = data_dir / "outdoor.sqlite3"
        self.index_path = data_dir / "outdoor.hnsw"

        self._conn: sqlite3.Connection | None = None
        self._index: hnswlib.Index | None = None
        self._embedder: Any = None

    def open(self) -> None:
        """Open database and load index."""
        # SQLite with FTS5
        self._conn = sqlite3.connect(str(self.db_path))
        self._conn.row_factory = sqlite3.Row
        self._init_schema()

        # Hnswlib index
        if self.index_path.exists():
            self._index = hnswlib.Index(space="cosine", dim=self.EMBEDDING_DIM)
            self._index.load_index(str(self.index_path))
            self._index.set_ef(50)  # Search accuracy vs speed

    def _init_schema(self) -> None:
        """Initialize SQLite schema with FTS5."""
        self._conn.executescript("""
            CREATE TABLE IF NOT EXISTS entries (
                id TEXT PRIMARY KEY,
                category TEXT NOT NULL,
                title TEXT NOT NULL,
                content TEXT NOT NULL,
                safety_level TEXT NOT NULL,
                safety_notes TEXT,
                sources TEXT,  -- JSON array
                tags TEXT      -- JSON array
            );

            CREATE VIRTUAL TABLE IF NOT EXISTS entries_fts USING fts5(
                title, content, tags,
                content='entries',
                content_rowid='rowid'
            );

            CREATE TRIGGER IF NOT EXISTS entries_ai AFTER INSERT ON entries BEGIN
                INSERT INTO entries_fts(rowid, title, content, tags)
                VALUES (new.rowid, new.title, new.content, new.tags);
            END;
        """)
        self._conn.commit()

    def search(
        self,
        query: str,
        category: str | None = None,
        limit: int = 5,
    ) -> list[dict[str, Any]]:
        """Search using hybrid FTS5 + vector similarity."""
        # FTS5 keyword search
        fts_results = self._fts_search(query, category, limit * 2)

        # Vector semantic search (if embedder available)
        if self._index and self._embedder:
            vector_results = self._vector_search(query, category, limit * 2)
            # Combine and re-rank
            return self._hybrid_rank(fts_results, vector_results, limit)

        return fts_results[:limit]

    def _fts_search(
        self,
        query: str,
        category: str | None,
        limit: int,
    ) -> list[dict[str, Any]]:
        """Full-text search using FTS5."""
        sql = """
            SELECT e.*, bm25(entries_fts) as score
            FROM entries e
            JOIN entries_fts ON e.rowid = entries_fts.rowid
            WHERE entries_fts MATCH ?
        """
        params = [query]

        if category and category != "all":
            sql += " AND e.category = ?"
            params.append(category)

        sql += " ORDER BY score LIMIT ?"
        params.append(limit)

        cursor = self._conn.execute(sql, params)
        return [dict(row) for row in cursor.fetchall()]

    def _vector_search(
        self,
        query: str,
        category: str | None,
        limit: int,
    ) -> list[dict[str, Any]]:
        """Semantic search using Hnswlib."""
        query_vec = self._embedder.embed([query])[0]
        labels, distances = self._index.knn_query(query_vec, k=limit)

        results = []
        for label, dist in zip(labels[0], distances[0]):
            entry = self._get_entry_by_rowid(int(label))
            if entry:
                if category and category != "all" and entry["category"] != category:
                    continue
                entry["vector_score"] = 1 - dist  # Convert distance to similarity
                results.append(entry)

        return results

    def _hybrid_rank(
        self,
        fts_results: list[dict],
        vector_results: list[dict],
        limit: int,
    ) -> list[dict[str, Any]]:
        """Combine FTS and vector results with reciprocal rank fusion."""
        scores: dict[str, float] = {}
        entries: dict[str, dict] = {}

        # RRF constant
        k = 60

        for rank, entry in enumerate(fts_results):
            entry_id = entry["id"]
            scores[entry_id] = scores.get(entry_id, 0) + 1 / (k + rank + 1)
            entries[entry_id] = entry

        for rank, entry in enumerate(vector_results):
            entry_id = entry["id"]
            scores[entry_id] = scores.get(entry_id, 0) + 1 / (k + rank + 1)
            entries[entry_id] = entry

        # Sort by combined score
        sorted_ids = sorted(scores.keys(), key=lambda x: scores[x], reverse=True)

        return [entries[eid] for eid in sorted_ids[:limit]]
```
