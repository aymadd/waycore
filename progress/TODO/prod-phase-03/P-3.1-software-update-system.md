## Description

Design and implement a secure, reliable software update mechanism for Waycore devices. Users need a straightforward way to update their device software, whether connected to the internet or via offline methods. The system must handle partial updates, rollbacks, and ensure the device remains functional even if an update fails.

### Update Methods

1. **Over-the-Air (OTA) Updates**
   - Check for updates via WiFi/LTE when connected
   - Download delta updates to minimize bandwidth
   - Background download with user approval for install
   - Automatic security patches (optional, user-configurable)

2. **USB/SD Card Updates**
   - Download update package on computer
   - Transfer to USB drive or SD card
   - Device detects and offers to install
   - Useful for field updates without connectivity

3. **Local Network Updates**
   - Push updates from a computer on same network
   - Web interface or CLI tool for power users
   - Useful for fleet management scenarios

### Update Components

| Component | Update Method |
|-----------|---------------|
| System services | Docker container images or systemd units |
| UI application | Python/QML package bundle |
| Firmware (ESP32) | OTA via serial bridge from main SBC |
| AI models | Separate model package downloads |
| Configuration | Versioned config migrations |

### Safety Requirements

- **Atomic updates** — Update succeeds completely or rolls back
- **A/B partitions** — Fallback to previous version if boot fails
- **Integrity verification** — Signed packages, checksum validation
- **Battery check** — Refuse update below 30% battery
- **Rollback capability** — User can revert to previous version
- **Backup user data** — Preserve notes, settings, photos during update

### Update Flow

1. Check for updates (manual or scheduled)
2. Download update package in background
3. Verify package signature and checksum
4. Notify user update is ready
5. User approves installation
6. Install to inactive partition/slot
7. Reboot into new version
8. Verify boot success, mark as good
9. If boot fails, auto-rollback to previous

## Technical Notes

### Package Format

```
waycore-update-1.2.0.wcu
├── manifest.json         # Version, checksums, dependencies
├── signature.sig         # GPG/minisign signature
├── services/             # Docker images or service bundles
├── ui/                   # UI application bundle
├── firmware/             # ESP32 binary (optional)
├── models/               # AI model updates (optional)
└── migrations/           # Config migration scripts
```

### Update Service API

```
GET  /api/updates/check          # Check for available updates
GET  /api/updates/current        # Current version info
POST /api/updates/download       # Start download
GET  /api/updates/download/status # Download progress
POST /api/updates/install        # Install downloaded update
POST /api/updates/rollback       # Rollback to previous
GET  /api/updates/history        # Update history
```
