## Description

Update the AI chat gallery image picker to select images from actual device storage instead of using Qt's FileDialog which may not work correctly on the embedded Linux device with touch interface.

## Current State

- Gallery picker uses Qt `FileDialog` component
- Works on desktop development environment
- May not integrate properly with device's photo storage
- No integration with the Gallery app's photo list

## Target State

- AI gallery picker integrates with device photo storage
- Picker shows photos from the Gallery app's storage location
- Touch-friendly grid view of available photos
- Smooth integration with camera-captured photos

## Technical Details

### Device Storage Locations

```
/app/data/photos/          # Camera app storage
/app/data/gallery/         # Gallery app index
```

### Implementation Options

1. **Reuse Gallery Component**: Create a shared photo picker component that
   both Gallery app and AI chat can use

2. **API-Based**: Add an endpoint to fetch available photos, AI picks from list

3. **Native Picker**: Use platform-native image picker if available on the
   target Linux distribution
