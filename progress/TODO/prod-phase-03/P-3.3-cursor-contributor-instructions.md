1. Contributing changes to the core project

## Implementation Notes

### Key Rules to Include

```markdown
## Critical Rules

1. **Type Safety**
   - All Python functions must have type hints
   - Use `from __future__ import annotations`
   - Run `mypy --strict` before committing

2. **UI Consistency**
   - Always use App.Theme for colors, fonts, spacing
   - Import components as `import "components" as UI`
   - Minimum touch target: 48px

3. **Service Pattern**
   - Extend BaseService for lifecycle management
   - Expose /health endpoint
   - Use Pydantic models for request/response

4. **Testing**
   - Tests required for new functionality
   - Minimum 80% coverage for services
   - Use pytest-asyncio for async tests

5. **Documentation**
   - Update relevant docs when changing behavior
   - Add docstrings to public functions
   - Update progress tracking for task work
```

### Example Patterns Section

```markdown
## Adding a New Sensor

1. Define interface in `device/libs/hil/interfaces/`
2. Create mock driver in `device/drivers/mock/`
3. Register in DriverFactory
4. Add schema in `device/libs/schemas/`
5. Expose via service API
6. Add UI component to display data
7. Write tests for each layer
```
