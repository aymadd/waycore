## Description

Create a Gallery app UI in QML that displays all captured photos in a grid view. Users can tap photos to view them full-screen, and delete photos they no longer need. The gallery fetches photo data from the camera service API.

### UI Components

1. **Grid View (Main Screen)**
   - Thumbnail grid showing all photos
   - 3-column layout (configurable)
   - Sorted by date (newest first)
   - Empty state message when no photos
   - Pull-to-refresh or auto-refresh on open

2. **Photo Detail View**
   - Full-screen photo display
   - Pinch-to-zoom (optional for v1)
   - Swipe left/right to navigate between photos
   - Photo metadata display (date, size)
   - Delete button with confirmation

3. **Delete Confirmation**
   - Dialog: "Delete this photo?"
   - Confirm/Cancel buttons
   - Toast notification after deletion

4. **Navigation**
   - Back button in gallery returns to Home
   - Back button in detail view returns to grid
   - Camera shortcut to quickly take new photo (optional)

### User Flows

**Viewing Photos:**
1. User opens Gallery from Home grid
2. Grid displays thumbnails of all photos
3. User taps a photo
4. Full-screen detail view opens
5. User can swipe to other photos or go back

**Deleting Photos:**
1. User is viewing a photo in detail view
2. User taps delete icon
3. Confirmation dialog appears
4. User confirms deletion
5. Photo removed, returns to grid (or next photo)

### Empty State

When no photos exist:
- Friendly message: "No photos yet"
- Camera icon or illustration
- "Take your first photo" button linking to Camera app

## Implementation Notes

### Grid Layout

```qml
GridView {
    id: photoGrid
    anchors.fill: parent
    anchors.margins: App.Theme.spacingSmall

    cellWidth: width / 3
    cellHeight: cellWidth  // Square thumbnails

    model: photoListModel

    delegate: Item {
        width: photoGrid.cellWidth
        height: photoGrid.cellHeight

        Image {
            anchors.fill: parent
            anchors.margins: 2
            source: model.thumbnailUrl
            fillMode: Image.PreserveAspectCrop

            MouseArea {
                anchors.fill: parent
                onClicked: openPhotoViewer(model.id)
            }
        }
    }
}
```
