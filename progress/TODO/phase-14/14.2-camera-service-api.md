## Description

Create a camera service that manages camera operations and exposes REST API endpoints for the UI to interact with. This service acts as the bridge between the camera driver (mock or real) and the application layer, handling photo capture, storage, and camera state management.

### Service Responsibilities

1. **Camera Control**
   - Initialize and manage camera driver lifecycle
   - Handle capture requests from API
   - Manage camera settings (resolution, etc.)

2. **Photo Storage**
   - Save captured photos to designated directory
   - Generate unique filenames with timestamps
   - Store photo metadata (timestamp, resolution, size)

3. **Photo Management**
   - List all photos with metadata
   - Delete photos
   - Get photo details

### API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/camera/status` | Get camera state (ready, capturing, error) |
| POST | `/api/camera/capture` | Take a photo, return photo info |
| GET | `/api/camera/settings` | Get current camera settings |
| PUT | `/api/camera/settings` | Update camera settings |
| GET | `/api/photos` | List all photos with metadata |
| GET | `/api/photos/{id}` | Get single photo details |
| GET | `/api/photos/{id}/file` | Get photo file (binary) |
| DELETE | `/api/photos/{id}` | Delete a photo |

### Photo Metadata Schema

```python
class PhotoMetadata:
    id: str              # Unique identifier (UUID or filename)
    filename: str        # Original filename
    filepath: str        # Full path to file
    timestamp: datetime  # When photo was taken
    width: int           # Image width in pixels
    height: int          # Image height in pixels
    size_bytes: int      # File size
    thumbnail: str       # Base64 encoded thumbnail (optional)
```
