## Description

Implement the Info submenu within Settings to display comprehensive device and application information. This screen provides users with detailed system information useful for support, debugging, and verification. The content is read-only and informational.

### Information Sections to Display

1. **Device Information**
   - Device model (e.g., "Waycore Dev Board v1.0")
   - Serial number (unique device identifier)
   - Hardware revision
   - Hostname
   - MAC addresses (WiFi, Bluetooth, LoRA)
   - CPU information (architecture, cores)
   - Total RAM
   - Storage type (eMMC, SD, etc.)

2. **Software Information**
   - App version (e.g., "0.1.0-dev")
   - Build number / Git commit hash
   - Build date
   - Python version
   - Qt/QML version
   - OS version (Linux kernel, distro)

3. **Network Information**
   - Current IP addresses (WiFi, Ethernet, LTE)
   - Gateway
   - DNS servers
   - LoRA node ID

4. **Runtime Information**
   - System uptime
   - App uptime (time since launch)
   - Current memory usage
   - CPU temperature (if available)
   - Battery status summary

5. **Legal & Licenses** (optional, expandable section)
   - Open source licenses
   - Terms of use link
   - Privacy policy link

### UI Design

- Use a clean, card-based layout with clear section headers
- Information displayed as key-value pairs
- Consider "Copy to clipboard" functionality for support purposes
- Scrollable content area
- All data is read-only (no interactive controls except navigation)

### Backend Integration

- Fetch device info from core_daemon API
- Most values already available via SensorBridge
- Add any missing endpoints for new information
