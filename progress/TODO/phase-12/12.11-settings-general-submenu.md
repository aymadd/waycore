## Description

Implement the General submenu within Settings containing core device preferences and system controls. This consolidates the most frequently accessed settings into one organized location. The General submenu includes unit preferences, display settings, developer options, storage information, and factory reset functionality.

### Settings Sections to Implement

1. **Units** (migrate from current Settings.qml)
   - Temperature: Celsius / Fahrenheit
   - Distance: Kilometers / Miles
   - Weight: Kilograms / Pounds
   - Pressure: hPa / inHg / mmHg
   - Time format: 12-hour / 24-hour

2. **Display**
   - Brightness slider (0-100%)
   - Auto-brightness toggle (future hardware support)
   - Screen timeout dropdown (30s, 1m, 2m, 5m, Never)

3. **Developer Options**
   - Debug mode toggle
   - Theme selection (dark/light)
   - Show FPS counter toggle
   - Enable verbose logging toggle
   - API endpoint override (text field)

4. **Storage Usage** (NEW - requires backend mock)
   - Total storage capacity (e.g., 32GB)
   - Used storage with breakdown:
     - System: X GB
     - Apps: X GB
     - Data (notes, logs): X GB
     - Available: X GB
   - Visual progress bar showing usage
   - "Clear Cache" button

5. **Factory Reset** (migrate from current Settings.qml)
   - Warning text about data loss
   - Two-tap confirmation button
   - Progress indicator during reset

### Backend Requirements for Storage

Create a mock storage status endpoint that returns:
- Total capacity in bytes
- Used space breakdown by category
- Available space

This will be replaced with real filesystem queries on actual hardware.
