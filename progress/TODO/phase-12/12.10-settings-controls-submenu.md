## Description

Implement the Controls submenu within Settings to manage radio and connectivity hardware. This screen provides toggle switches and status displays for all wireless communication modules. Users can enable/disable each radio independently to conserve power or manage connectivity preferences.

### Radio Controls to Implement

1. **LoRA (Meshtastic)**
   - On/Off toggle switch
   - Status: Connected/Disconnected/Error
   - Additional info: Channel, TX power, node count when connected
   - Last transmission timestamp

2. **WiFi**
   - On/Off toggle switch
   - Status: Connected/Disconnected/Scanning
   - Network name (SSID) when connected
   - Signal strength indicator
   - IP address when connected

3. **Bluetooth**
   - On/Off toggle switch
   - Status: On/Off/Pairing
   - Connected device count
   - List of paired devices (expandable)

4. **LTE/Cellular**
   - On/Off toggle switch
   - Status: Connected/No Signal/Roaming
   - Signal bars indicator
   - Carrier name when connected
   - Data usage summary (optional)

### UI Design

Each radio should be displayed as a card with:
- Radio name and icon (📡 LoRA, 📶 WiFi, 🔵 Bluetooth, 📱 LTE)
- Large toggle switch for on/off
- Status text with appropriate color coding
- Expandable section for additional details
- Visual feedback when state changes (brief loading indicator)

### Backend Integration

- Call radio control endpoints to enable/disable radios
- Poll status periodically (every 3-5 seconds)
- Use mock radio drivers for development
- Handle state changes asynchronously with loading states
