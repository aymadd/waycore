## Description

Replace mocked storage values with actual filesystem metrics on Raspberry Pi. Currently, the storage endpoint mocks total capacity (32GB), system size (2GB), and apps size (500MB). In production, these should reflect real disk usage.

### Current Mock Values

```python
total_bytes = 32 * 1024 * 1024 * 1024  # 32 GB (mocked)
system_bytes = 2 * 1024 * 1024 * 1024   # 2 GB (mocked)
apps_bytes = 500 * 1024 * 1024          # 500 MB (mocked)
```

### Production Implementation

```python
import shutil
from pathlib import Path

# Total and available from actual filesystem
disk = shutil.disk_usage("/")
total_bytes = disk.total
available_bytes = disk.free

# Apps: measure actual installation directory
apps_path = Path("/opt/waycore")  # or wherever we install
apps_bytes = sum(f.stat().st_size for f in apps_path.rglob("*") if f.is_file())

# System: derive from total - apps - data - available
system_bytes = total_bytes - apps_bytes - data_bytes - available_bytes
```

### Environment Flag

Add `WAYCORE_PRODUCTION=true` environment variable to switch from mock to real values.
