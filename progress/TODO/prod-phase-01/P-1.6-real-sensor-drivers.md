## Description

Replace mock sensor drivers with real hardware drivers for Raspberry Pi 5. This includes implementing actual I2C/SPI communication with physical sensors connected to the device.

### Sensors to Implement

1. **GPS Module** (e.g., NEO-6M, NEO-M8N)
   - Serial/UART interface
   - NMEA sentence parsing
   - Latitude, longitude, altitude, speed, satellites

2. **Temperature/Pressure** (e.g., BME280, BMP280)
   - I2C interface
   - Temperature in Celsius/Fahrenheit
   - Barometric pressure
   - Altitude calculation from pressure

3. **Magnetometer/Compass** (e.g., HMC5883L, QMC5883L, ICM-20948)
   - I2C interface
   - Heading in degrees
   - Calibration routines
   - Declination adjustment

4. **Accelerometer/Gyroscope** (e.g., MPU6050, ICM-20948)
   - I2C interface
   - 3-axis acceleration
   - 3-axis rotation
   - Tilt detection

5. **Light Sensor** (e.g., BH1750, TSL2561)
   - I2C interface
   - Lux measurement
   - Auto-ranging

6. **Battery Monitor** (e.g., INA219, MAX17043)
   - I2C interface
   - Voltage, current, power
   - State of charge percentage

- `device/drivers/gps/neo_m8n.py` - GPS driver
- `device/drivers/temperature/bme280.py` - Temp/pressure driver
- `device/drivers/magnetometer/qmc5883l.py` - Compass driver
- `device/drivers/accelerometer/mpu6050.py` - Accel/gyro driver

- `device/drivers/battery/ina219.py` - Battery monitor driver
- `device/libs/sensors/hardware_scanner.py` - I2C/SPI device scanner

## Hardware Requirements

- Raspberry Pi 5 with I2C enabled
- Connected sensors on I2C bus (0x76 BME280, 0x0D QMC5883L, etc.)
- GPS module connected via UART
