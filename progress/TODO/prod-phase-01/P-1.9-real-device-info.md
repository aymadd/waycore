### Raspberry Pi Hardware Info Sources

1. **Model and Revision**
   ```bash
   cat /proc/device-tree/model
   # Output: Raspberry Pi 5 Model B Rev 1.0

   cat /proc/cpuinfo | grep Model
   cat /proc/cpuinfo | grep Revision
   cat /proc/cpuinfo | grep Serial
   ```

2. **CPU Temperature**
   ```bash
   cat /sys/class/thermal/thermal_zone0/temp
   # Output: 45000 (divide by 1000 for Celsius)
   ```

3. **Memory Info**
   ```bash
   cat /proc/meminfo | grep MemTotal
   cat /proc/meminfo | grep MemAvailable
   ```

4. **Network Info**
   ```python
   import netifaces
   # Get MAC addresses, IP addresses for all interfaces
   ```

5. **Uptime**
   ```bash
   cat /proc/uptime
   # Output: 12345.67 123.45 (seconds since boot)
   ```

### Implementation

```python
def get_device_model() -> str:
    model_path = Path("/proc/device-tree/model")
    if model_path.exists():
        return model_path.read_text().strip().rstrip('\x00')
    return "Unknown Device"

def get_serial_number() -> str:
    with open("/proc/cpuinfo") as f:
        for line in f:
            if line.startswith("Serial"):
                return line.split(":")[1].strip()
    return "Unknown"

def get_cpu_temp() -> float:
    temp_path = Path("/sys/class/thermal/thermal_zone0/temp")
    if temp_path.exists():
        return int(temp_path.read_text().strip()) / 1000
    return 0.0
```
