## Description

Implement actual screen brightness control for the Raspberry Pi display. Currently, brightness is stored as a preference but doesn't affect the physical display. In production, brightness changes should control the actual backlight.

### Raspberry Pi Display Methods

1. **Official 7" Touchscreen** (DSI)
   ```bash
   # Brightness range: 0-255
   echo 128 > /sys/class/backlight/rpi_backlight/brightness
   ```

2. **HDMI Displays with DDC/CI**
   ```bash
   # Using ddcutil
   ddcutil setvcp 10 50  # Set brightness to 50%
   ```

3. **GPIO-controlled Displays**
   - PWM on backlight pin
   - Requires custom driver

### Implementation

Create a display driver abstraction:

```python
class DisplayDriver:
    def set_brightness(self, percent: int) -> bool:
        """Set brightness 0-100%"""
        pass

    def get_brightness(self) -> int:
        """Get current brightness 0-100%"""
        pass

class RPiBacklightDriver(DisplayDriver):
    BACKLIGHT_PATH = "/sys/class/backlight/rpi_backlight/brightness"
    MAX_BRIGHTNESS = 255

    def set_brightness(self, percent: int) -> bool:
        value = int((percent / 100) * self.MAX_BRIGHTNESS)
        Path(self.BACKLIGHT_PATH).write_text(str(value))
        return True
```

### Screen Timeout / Dimming

- Implement screen timeout based on user preference
- Dim to 20% after inactivity
- Turn off backlight completely after extended timeout
- Wake on touch/button input
