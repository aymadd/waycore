# Security Policy

We take security seriously. Thank you for responsibly disclosing vulnerabilities.

## Reporting
- Please avoid opening public issues for security reports.
- Send a detailed report to the maintainers (contact listed in repository settings or organization page).
- Include steps to reproduce, impacted components, and potential impact.

## Scope
This repository and its artifacts (services under `device/` and docs) are in scope.

## Response
We aim to acknowledge reports within 72 hours and will coordinate on a fix and disclosure timeline.
