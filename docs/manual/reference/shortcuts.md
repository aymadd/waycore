# Keyboard Shortcuts & Gestures

> Quick actions for faster navigation

## Gestures

### Navigation Gestures

| Gesture | Action |
|---------|--------|
| Tap | Select/activate |
| Swipe left from edge | Go back |
| Swipe down from top | Return to home |
| Pull down | Refresh (in lists) |
| Pinch | Zoom in/out (in photos/maps) |
| Double-tap | Toggle zoom (in photos) |

### App-Specific Gestures

#### Gallery
| Gesture | Action |
|---------|--------|
| Swipe left/right | Next/previous photo |
| Pinch | Zoom |
| Double-tap | Toggle zoom |

#### Maps
| Gesture | Action |
|---------|--------|
| Drag | Pan map |
| Pinch | Zoom |
| Double-tap | Zoom in |
| Two-finger tap | Zoom out |

#### Notes
| Gesture | Action |
|---------|--------|
| Swipe left on note | Delete option |
| Pull down | Refresh list |

## Hardware Buttons

### Power Button

| Action | Result |
|--------|--------|
| Short press | Wake/sleep screen |
| Hold 2 seconds | Power menu |
| Hold 5 seconds | Force power off |

### Volume Buttons (if available)

| Action | Result |
|--------|--------|
| Volume up | Increase volume |
| Volume down | Decrease volume |
| Both + Power | Screenshot (some devices) |

## Quick Actions

### Status Bar
Tap status bar items for quick info:
- **Battery icon**: Battery details
- **Time**: Full date and time
- **Signal icon**: Connection status

### Home Screen
- **Long-press app**: App options (if available)
- **Tap and hold empty space**: Customization options (future)

## Accessibility

### Text Size
Adjust in Settings → General → Text Size

### High Contrast
Enable in Settings → General → High Contrast (if available)

## Tips

### Faster Navigation
- Learn the back swipe gesture
- Use home swipe to quickly exit any app
- Memorize common app locations on home screen

### In the Field
- Keep gestures simple with gloves
- Use larger tap targets in cold weather
- Consider stylus for precision
