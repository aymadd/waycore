# Factory Reset

> Reset your device to default settings

## Overview

A factory reset restores your Waycore device to its original state. This should be used as a last resort for troubleshooting or before transferring the device.

## What Gets Reset

### Cleared by Factory Reset
- ✅ All user settings
- ✅ All notes
- ✅ All photos
- ✅ All saved locations/waypoints
- ✅ AI conversation history
- ✅ Mesh contacts and messages
- ✅ App preferences
- ✅ WiFi passwords

### Preserved
- ✅ Operating system
- ✅ Installed applications
- ✅ AI model (stays installed)
- ✅ System software version

## Before You Reset

### Consider Alternatives
1. **Restart the device** — fixes most issues
2. **Clear app data** — for app-specific problems
3. **Check troubleshooting guide** — may have a simpler solution

### Backup Your Data
Factory reset cannot be undone. Before proceeding:

1. **Notes**: Export or photograph important notes
2. **Photos**: Transfer to computer or cloud
3. **Coordinates**: Write down important waypoints
4. **Settings**: Note any custom configurations

## How to Factory Reset

### Method 1: Settings Menu

1. Go to **Settings → Advanced**
2. Tap **Factory Reset**
3. Read the warning message
4. Enter PIN or confirmation if prompted
5. Tap **Reset Device**
6. Wait for the process to complete (2-5 minutes)
7. Device will restart with default settings

### Method 2: Recovery Mode (if Settings unavailable)

1. Power off the device
2. Hold **Power + Volume Down** (varies by model)
3. Select **Factory Reset** from recovery menu
4. Confirm the action
5. Wait for process to complete
6. Device restarts with defaults

## After Factory Reset

### First-Time Setup
After reset, you'll go through initial setup:

1. Select language and region
2. Configure WiFi (optional)
3. Set date and time
4. Accept terms of use

### Reconfigure Settings
Restore your preferred settings:
- Display brightness
- Auto-sleep timeout
- Sensor calibration
- Mesh radio settings

### Re-download Maps
If you need offline maps:
1. Connect to WiFi
2. Open Maps app
3. Download your areas

## Troubleshooting

### Reset is stuck
If the reset process seems frozen:
1. Wait at least 10 minutes
2. If still stuck, hold power button 10 seconds
3. Device will restart
4. May need to try reset again

### Device won't start after reset
1. Connect to charger
2. Wait 5 minutes
3. Try power button
4. If no response, contact support

### Settings were not cleared
Some settings may require an additional step:
1. Complete the reset process
2. If issues persist, try reset again
3. Contact support if problems continue

## Selective Resets

For less drastic options:

### Clear App Data
Reset individual apps:
1. Settings → Apps → [App Name]
2. Tap "Clear Data"
3. Only affects that app

### Reset Network Settings
Clear WiFi and Bluetooth:
1. Settings → General → Reset Network
2. Clears saved networks
3. Preserves other data

### Clear AI History
Remove just conversations:
1. AI App → History
2. Tap "Clear All"
3. Confirms deletion

## When to Contact Support

Contact support instead of resetting if:
- Device has hardware damage
- Screen is unresponsive
- Boot loop occurs
- You see error codes on startup

**Save reset as last option** — support may have other solutions.
