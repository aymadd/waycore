# Notes

> Quick notes and reminders for the field

## Overview

The Notes app lets you capture text notes quickly. Notes are stored locally and
persist across restarts.

## Getting Started

1. From the Home screen, tap **Notes** (📝)
2. You'll see a list of your notes (empty on first use)
3. Tap **+ New Note** to create your first note

## Creating Notes

### New Note

1. Tap **+ New Note** at the bottom
2. Enter a title (optional but recommended)
3. Write your note content
4. Tap **Save** or navigate away (auto-saves)

### Quick Note

Start typing immediately — title is optional. Notes without titles show the
first line as the title.

## Organizing Notes

### Note List

Notes are displayed chronologically with:

- Title (or first line if no title)
- Preview of content
- Last modified date

### Editing

1. Tap any note to open it
2. Make changes
3. Changes save automatically

### Deleting

1. Swipe left on a note
2. Tap **Delete**
3. Confirm deletion

**Note**: Deleted notes cannot be recovered.

## Use Cases

### Field Observations

Record wildlife sightings, plant locations, or terrain notes.

### Coordinates

Save GPS coordinates from the Compass app with context.

### Trip Planning

Create checklists and itineraries.

### AI Responses

Save important information from AI conversations.

## Tips

### Quick Access

Notes is available from the home screen for fast access.

### Timestamps

Notes automatically record when they were created and modified.

### Offline

All notes are stored locally — no internet needed.

### Storage

Notes use minimal storage. You can store thousands of notes.

## Troubleshooting

### Notes not saving

- Wait a moment — auto-save may be in progress
- Check storage space in Settings → Info
- Restart the app if issues persist

### Can't find a note

- Scroll through the list
- Check if accidentally deleted
- Notes are sorted by last modified date

### App crashes when opening

- May indicate storage issue
- Restart the device
- Check Settings → Info for storage status
